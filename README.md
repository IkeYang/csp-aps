# csp-aps

光热塔式电站（圆柱外置集热器）**设计仿真、镜场自动布置与实时瞄准策略（APS）**软件原型。

已按导师评审稿（2026-11-20，基线 0d9292d）逐条落实，对应关系见 [docs/REVIEW_RESPONSE.md](docs/REVIEW_RESPONSE.md)；模型细节见 [docs/MODEL.md](docs/MODEL.md)。

后续开发的优先级、年度布局排名复算方法和面向首次使用者的界面验收任务，见[镜场优化改进方案与新手工程师验收指南](docs/APS-IMPROVEMENT-PLAN.md)。

## 0.6.0 按改进方案：首次使用流程、排名口径与算法证据

按 [改进方案](docs/APS-IMPROVEMENT-PLAN.md) 实现，推导见 [模型说明 0.6 节](docs/MODEL.md)，逐条对应见方案文末的实施记录。

**第一次打开。** 首页有两个入口：“镜子已经装好，计算瞄准点”和“镜子尚未安装，比较全年布局”。每个入口都可以用示例试算，也可以下载与任务匹配的 CSV 模板。布局页默认是“比较两套已有布局”，分五步：

1. 场地与镜位核对；
2. 工况清单与 DNI 地图预览；
3. 一个“更重视吸热量 ↔ 更重视受热均匀”的滑块，可先选一个工况试算；
4. 开算前汇总，计算中可取消，已完成的工况保留；
5. 结果先行：A/B 并列，工况按对分差的贡献排序。

改参数后旧结果会提示“需要重新计算”。DNI 表有错时，页面指出第几行、哪一列，并高亮该行。方案列出的五项首次使用任务由 `tests/test_first_user_acceptance.py` 在界面上自动完成。

**会改变排名的口径。**

- 代表工况用实际小时和时间平均 DNI。阿克塞 20 个工况合计 4,028 实际小时，0.5 的等效小时是 2,800.62。
- 只有细网格复核峰值不超过上限 95% 的方案才算可行。
- 运行与评价默认共用一个 λ。
- 取消时报告覆盖率，未算完的布局标为“排名待定”。等权重时给出年度价值区间。

“选错址”示例（`cases/wrong_site`，界面“布局示例”一键载入）：

| 给两套布局的输入 | 布局 A（塔北） | 布局 B（塔南） | 得分较高 |
| --- | ---: | ---: | --- |
| 每张图的全场平均 DNI | 72.817 | 59.142 | A |
| 同样的 20 张图，按各自镜位取 DNI | 41.449 | 84.785 | B |

三个演示站址的吸热器峰值不到上限的 20%，限值不起作用。此时吸收功率和不均匀量都与 DNI 成正比，两种小时口径给出完全相同的 V：阿克塞重算为 28,976.2 MWhₜₕ，与 0.5.0 逐位相同，只有报告的小时数改为实际小时。口径只在限值或最低负荷起作用时改变结果（[模型说明 0.6.1](docs/MODEL.md)）。

### 算法值得升级吗：同一条件下的证据（阿克塞，473 面镜）

`python scripts/solver_benchmark.py` 复现，结果写入 `results/solver_benchmark/`。

**光线追迹复核四个压力工况**（界面「光学校验 → 压力工况复核」）。每个工况都是正式内层设置求出的方案；解析模型与 MCRT 用同一方案、同一 48 × 24 网格，每镜 2000 条光线，种子 7–10。差值方向为解析 − 追迹。

- **功率**：四个工况的差都在 0.15% 以内。
- **峰值**：
  - 低太阳高度时解析模型低估 5%（标准误 0.2%），属于模型误差：低太阳时像散使光斑变形，HFLCAL 的圆高斯光斑近似在这里偏差最大；这时热流离上限很远。
  - 高负荷时解析模型高估 4.6%，偏保守。
  - 逼近限制时两者相差 0.1%，追迹确认峰值为上限的 0.884 ± 0.009，在 95% 的允许值以内。
- **噪声的影响**：每镜只用 300 条光线时，云影边缘的峰值差是 −11.5%，主要来自噪声图最大值的偏高；加密后为 −0.9%。
- **热点距离**：λ = 0.3 的方案热流很平，最热格可在几米外的平台上任意落点，所以热点距离 3.7–4.7 m 只说明两图的最大值不在同一格，不说明热点位置算错。
- **求解差距**：低太阳时的 24% 来自上界不计阴影遮挡，并不说明方案差。

**内层：四种瞄准方法**（界面「光学校验 → 求解器对比」）。取 h_s × DNI 最大的 6 个工况，候选集、网格与 5% 裕度相同，每种方法每个工况的预算为 60 s。差距相对每个工况所有方法中最小的有效上界。

| 方法 | 算例设置（λ = 0.3，限值 1000 kW/m² 不起作用）：平均 / 最大差距 · 平均用时 | 限值起作用（λ = 0，限值 388 kW/m²）：平均 / 最大差距 · 平均用时 |
| --- | --- | --- |
| 贪心 APS（现行） | 0.23% / 0.29% · 6.9 s | 0.004% / 0.025% · 2.6 s |
| 固定响应 0/1 规划（HiGHS） | 0.22% / 0.32% · 40.6 s（1 个工况超预算） | 同上 · 63.9 s（用满时限） |
| 子场分解（4 扇区，可并行） | 0.22% / 0.27% · 6.6 s（理想并行 6.5 s） | 同上 · 2.7 s |
| 贪心 + 松弛取整与对偶上界 | **0.06% / 0.07%** · 23.9 s，6 个工况都最好 | 同上 · 6.9 s |

全部 48 个方案都通过细网格复核。

- **松弛取整**：λ > 0 时把差距从 0.23% 降到 0.06%，用时约 3.5 倍。布局排名的价值区间重叠时值得打开（`layout_opt.inner_certify_rounds`）。
- **整数规划**：固定光斑响应的 0/1 规划不比贪心好，还慢 6–25 倍；它只最大化功率，均匀性要事后处理。
- **子场分解**：质量与贪心相同。473 面镜时扇区求解只占总时间的一小部分（响应计算与联合姿态复核占大头），所以并行收益不大，留作大镜场的选项。
- **限值起作用时**：四种方法给出同一方案，离上界不超过 0.025%。

**外层：两种布局搜索。** 同一场地、473 面镜、λ = 0.3，每次运行 300 s，种子 1、2。输出布局用正式 V(L) 在两组工况上评分：训练集是 12 个工况；留出集用种子 + 1000，有 17 个工况，代表太阳位置不同。

| 方法 | 评估次数 | V 训练（均值 ± 种子间标准差） | V 留出 | 相对初始镜场（训练 / 留出） | 留出名次 | 场界与最小镜距 |
| --- | --- | --- | --- | --- | --- | --- |
| 差分进化（现行） | 128–160 | 29,388 ± 2 | 29,049 ± 5 | +282 / +121 | 1、2 | 全部满足（最小间距 ≥ 12.8 m） |
| 多起点自由镜位（单镜能量梯度 + 斥力） | 2,778–2,818 | 29,172 ± 4 | 28,961 ± 15 | +66 / +32 | 3、4 | 全部满足（12.45 m，要求 12.45 m） |
| 初始镜场（参照） | — | 29,106 | 28,929 | 0 / 0 | — | — |

- 同样的时间预算下，参数化的差分进化在训练和留出工况上都明显领先，两个种子的结果几乎相同。
- 自由镜位法评估次数多约 20 倍，但只比初始镜场好 0.1–0.2%：单镜能量梯度把镜子推向塔，阴影遮挡和最小镜距又把它们挡回来。
- 两种方法在留出工况上的名次与训练工况一致，说明领先不是代表工况的偶然结果。

**结论**：

- 内层值得加松弛取整（约 3.5 倍时间）。默认不开，以免正式排名时间翻几倍；布局的价值区间重叠时，在「工况与地图的高级设置」里设 `inner_certify_rounds` 打开。
- 整数规划和子场分解在这个规模上没有收益。
- 外层保留差分进化。
- 解析模型的功率可直接用于排名。低太阳高度的峰值偏低约 5%，靠 5% 的安全裕度兜底；离上限近时应以细网格复核和光线追迹为准。

## 0.5.0 逐工况 APS 评价镜场的全年布局价值

按 [需求清单](docs/APS-LAYOUT-REQUIREMENTS.md) 全部实现并逐项验收，推导见 [模型说明 0.5 节](docs/MODEL.md)。

**怎样评价一套镜位。** 每个代表工况 s 给出太阳方向、代表小时数 h_s 和一张覆盖整个场地的 DNI 地图 D_s(x, y)（场地坐标，与布局无关）。镜子在哪里就读哪里的 DNI；每个参与排名的布局在每个工况下都重新求解问题一（内层权重 λ_APS，目标 P − λ_APS·U，U = A_H·σ_H 为考核区二维吸收热流的面积加权标准差乘面积，与问题一完全相同），再在**这组瞄准结果**上计分：

```
V(L) = Σ_s h_s (P_s − λ_L U_s) = E(L) − λ_L Π(L)          E = Σ_s h_s P_s（总吸热，单独报告），Π = Σ_s h_s U_s
```

- 内外层权重独立。两者相等时 V 就是各工况内层得分的加权和；只改 λ_L 时不重新求解，P_s、U_s 不变，V 沿斜率 −Π 的直线变化（界面拖动即重新排名）。
- 两套布局之差 ΔV = ΔE（更多吸热）+ (−λ_L ΔΠ)（更均匀受热）。先在每个工况考核热流不均匀，再按小时累加，不同时刻的热点不会在年平均热流图上相互抵消。
- 每个工况的状态与计分（可行运行计 h·(P − λ_L·U)；可行停机、无日照、未找到可行方案、已证不可行计 0；未求解则该布局不排名）写在结果表里。导出的逐工况表与逐镜瞄准方案可独立复算（`cspaps rescore`），`cspaps scenario-aps` 或界面「瞄准优化 → 年度工况复核」可独立复核任一工况，结果与布局工作区逐位一致。
- 中心瞄准只用于标注明确的快速初筛；初始镜场（最靠近塔的 N 面）一起排名作对照。外层上界在每个栅格取地图的 DNI 最大值，只对所用工况集成立。

**云影对比**（界面「云影对比与回放 → 单时刻云影对比」，`cspaps cloud-compare`）：云来之前的镜场 DNI、三维光束示意、各镜中心对应的瞄准点（标在吸热器展开图上）与热流；云来以后不改策略与重新 APS 的热流、总热量、均匀性（数值与图并列）；云突然散去仍执行云下方案的通量风险，以及按晴空 DNI 校核通量的防云散方案。

**结论**

1. **布局决定周向受热，三个站址一致。** 只追求能量时镜子挤向极侧（北半球塔北 95–100%，南半球的奥古斯塔港塔南 90%），管屏间 CV 0.9–1.3；λ_L = 0.3 时极侧占比降到 48–51%，CV 降到 0.11–0.28，代价是 4–15% 的理论能量。
2. **逐工况 APS 的正式排名可以逐项追溯，而且会改变结论。** 阿克塞、奥古斯塔港、哈密（均匀 DNI）的胜出布局比初始布局分别高 108、157、119 MWhₜₕ，优势来自更多吸热（ΔE +258 / +340 / +264），一部分被更不均匀的受热抵消（−150 / −183 / −145）。哈密的三个中心瞄准初筛布局在正式口径下都不如初始布局（−43 到 −78），只有按 V 接受的换位之后才反超——中心瞄准的初筛不能替代逐工况 APS 排名。
3. **代表工况误差小且不改变排序。** 20 个工况相对 40 个工况的 V 偏差为 +0.4% 到 +0.9%（持久性地图或均匀 DNI），各布局偏差相近，排序一致；10 张云图时为 +5%（每张云图只分到 2 个代表工况）。内层年度差距约 4%，最大单工况差距 15–26% 出现在太阳高度角 14–19° 的工况（上界放松了阴影遮挡，不是方案差）。
4. **空间 DNI 改变的主要是受热均匀性。** 持久性的半场亮暗或梯度使 Π 增加（阿克塞 +30%），V 下降约 1.4%；布局之间的领先幅度变化不大（阿克塞 +101 → +108，奥古斯塔港 +72 → +157）。
5. **瞬时云影不应决定镜位。** 哈密用云影地图做布局时，胜出布局只在自己的云图上领先初始布局（4 张云图 +4,861、10 张云图 +1,244 MWhₜₕ），换一组独立云图后落后（−844、−589），均匀 DNI 下也落后（−1,329）——优化器学会了躲开固定位置的云。在均匀 DNI 上设计的布局在两组独立云图上都稳定领先（+412、+269）。软件在云影模型下自动用独立云图复核胜出布局并在结果页提示（`layout_opt.cross_check_maps`）。镜位应按持久性的空间 DNI（或均匀 DNI）设计，云影地图用来检验运行与受热均匀性。
6. **云来时重新 APS 的价值在均匀性。** 两块云遮住 121 面镜：沿用晴空方案时吸收功率降约 20%，二维 CV 从约 0.24 升到 0.37–0.38；按云下 DNI 重新求解，功率基本不变而 CV 回到 0.25–0.34，目标 J 提高 0.33–0.59 MW。演示电站的吸热器不受通量限制（云散后执行云下方案的峰值为上限的 28–37%），所以防云散方案在这里不需要让步。

## 0.4.0 的两个设计工作区

**固定镜场瞄准。** 输入逐镜 XYZ、镜面尺寸、圆柱接收器及逐镜 DNI。选择功率最大、均匀性权重或 CV 上限。结果记录逐镜瞄准坐标、实际混合姿态下的吸收功率、考核区二维 CV 和热点。小规模问题枚举全部离散组合。较大问题通过松弛取整和联合姿态邻域搜索改进，并给出与所得方案对应的模型上界。允许散焦、最低负荷和设备通量限制均参与存在性判断。

**全年镜场布局。** 给定场界、镜数、镜面、接收器和站址气象。在最小镜距、边界与塔周禁排区内搜索布局。均匀性可选管屏之间或整个受热面的二维离散度。默认演示按中心瞄准的全年理论目标排名，标准预设对入围方案用实际逐时天气复算。切换到 APS 搜索时，按实际姿态的可行运行能量及其均匀性排名。每个结果注明瞄准策略、复核工况数、加权目标及其上界。

Windows 本地安装开发依赖后，双击仓库根目录的 `Start-CSP-APS.cmd`。命令行入口为 `cspaps gui`。模型边界、计算公式和证书范围见 [模型说明](docs/MODEL.md)。

### 0.3 历史阿克塞算例

本节保留旧版固定响应求解器的基准。旧表中的差距只对应当时的响应矩阵。0.4 结果页按联合姿态重算并使用独立上界。

阿克塞地区 2024 年 NASA POWER 逐时 DNI；镜场与吸热器为模拟设计输入（`cases/aksai_demo.yaml`）。

**问题一**：473 面 8×8 m 定日镜，吸热器 Ø7 × 8 m、中心高 100 m，2024-03-19 15:00，DNI 1136.7 W/m²。每一行都经过细网格完整光斑复核，差距相对可证上界。

| 均匀度权重 λ | 吸收功率 (MW) | 考核区二维 CV | 复核峰值 (kW/m²) | 最优性差距 |
| --- | --- | --- | --- | --- |
| 0（功率最大） | 24.188 | 1.101 | 561 | 0.00%（候选集上已证全局最优） |
| 0.05 | 24.001 | 0.528 | 242 | 0.00% |
| 0.1 | 23.721 | 0.370 | 200 | 0.02% |
| 0.2 | 23.415 | 0.280 | 194 | 0.06% |
| 0.3 | 23.272 | 0.259 | 195 | 0.10% |
| 0.5 | 22.283 | 0.161 | 162 | 0.43% |
| 1.0 | 21.148 | 0.089 | 147 | 1.17% |

- 只损失 0.8% 吸收功率（λ = 0.05），二维 CV 就从 1.10 降到 0.53；损失 3.8%（λ = 0.3）降到 0.26。
- 单时刻含证书的计算约 15–20 s（4 核）；7 个 λ 的权衡曲线约 1 分钟。
- 证书针对离散候选瞄准点（默认 21 个）。候选点加密分析（`cspaps aps-refine`）：3×7 → 5×13 → 9×25 个候选点时，本方案 21.462 → 21.562 → 21.595 MW，上界 21.487 → 21.587 → 21.611 MW，1.5° / 0.3 m 分辨率下差距 0.07%。
- 最终状态来自对最终瞄准点重新计算阴影遮挡后的细网格复核；只有通过复核的精确法最优解才标记“已证全局最优”。

**问题二**：N = 473，840 m × 780 m 矩形场地，塔周禁排半径 50 m，最小镜距 12.45 m。「标准」计算强度约 2–3 分钟。

圆柱外置式吸热器的每一侧只被朝向它的定日镜照射，APS 只能沿高度、在几度范围内移动瞄准点，**吸热器各朝向的受热由镜位决定**。只追求全年能量时，高纬度场址的镜子会挤在塔北侧，吸热器南侧几乎不受热，瞄准策略无法补救。所以布局目标加入周向均匀度惩罚：

```
max_X  Σ_t w_t [P_t(X) − λ_L · A_H · σ_circ,t(X)]      （与问题一的 P − λ·A_H·σ_H 同构）
```

σ_circ 是各管屏平均吸收热流的标准差（管屏间吸热平衡）。候选镜位按“加入当前布局后”的阴影遮挡定价，选择与定价交替迭代，避免把从不建造的候选的遮挡算进来而选出孤立远镜。

同一组生成参数下只改变 λ_L 的对比：

| 指标 | 只追求能量（λ_L = 0） | 演示默认 λ_L = 0.3 |
| --- | --- | --- |
| 塔北侧镜子占比 | 95% | 48% |
| 能量质心离塔 | 170 m | 13 m（集热器位于镜场中心） |
| 管屏间吸热 CV（逐工况、能量加权） | 1.07 | 0.12 |
| 脱离主镜场的镜子 | 0 | 0 |
| 全年理论吸收热量（中心瞄准，含阴影遮挡） | 35,826 MWhₜₕ | 33,709 MWhₜₕ（约 −6%） |
| 受限 APS 可行年吸收热量 | — | 32,167 MWhₜₕ |
| 任意布局、任意瞄准策略的年能量上界 / 差距 | 39,283 | 39,283 / ≤ 14.2%（多出的差距是均匀性的代价） |
| 候选集上镜位选择的差距（Frank–Wolfe 证书） | — | 0.04% |

两种布局在问题一中的表现（2024-03-19 15:00，DNI 1136.7 W/m²，细网格复核）：

| 问题一的权重 λ | 能量最优布局：吸收功率 / 二维 CV | λ_L = 0.3 布局：吸收功率 / 二维 CV |
| --- | --- | --- |
| 0 | 26.32 MW / 1.42 | 24.15 MW / 0.78 |
| 0.3 | 25.59 MW / 1.04 | 23.08 MW / 0.23 |
| 1.0 | 11.57 MW / 0.73 | 20.65 MW / 0.06 |

能量最优布局的周向 CV 在任何 λ 下都在 0.7 以上；环绕布局下瞄准策略能把二维 CV 降到 0.06，功率仍有 20.7 MW。界面「布局优化 → 能量–均匀度权衡」可以对任意 λ_L 序列画出这条曲线（每点数秒）。

上界忽略邻镜阴影遮挡并允许最密堆积，因此偏乐观；真实全局最优介于优化结果与上界之间。上界对栅格每个格子内的任意位置、任意瞄准点严格成立（不依赖格点取样），推导见 [docs/MODEL.md 第 0.2 节](docs/MODEL.md)。

| 外层布置优化 | 径向交错 / 仿生螺旋参数化布局 → 可选中心瞄准或 APS 年收益搜索 → 前几名按通过通量与均匀度检查后的吸收能量复核排名 → 换位微调 → 镜数、边界、禁排区、最小镜距最终校验（布不满时报告缺额） |
| 光学校验 | 内部 MCRT：独立误差项、多随机种子的统计不确定度、光线数收敛表。SolTrace 对标：导出同场算例和 PySolTrace 驱动脚本。遮挡筛选：与暴力求交逐镜比对 |

### 接入电站控制循环

**Python 接口**：

```python
from cspaps import load_case
from cspaps.field import build_field
from cspaps.engine import APSEngine, ControlRequest, ForecastSnapshot, Receipt

case = load_case("plant.yaml")
engine = APSEngine(case, build_field(case))
resp = engine.step(ControlRequest(
    time=now, dni=dni_per_heliostat, dni_time=t_meas,
    forecasts=[ForecastSnapshot(t, dni_t) for t, dni_t in forecast],
    available=in_service, receipt=Receipt(last.plan_id, last.aim_azimuth, last.aim_z, last.active)))
resp.state            # "ready" | "fallback" | "infeasible"
resp.to_frame()       # id, active, aim_azimuth_deg, aim_z, aim_x, aim_y, defocus_reason
```

**JSON 行服务**：`cspaps engine plant.yaml`。每行一个请求，DNI 可以用列表（按镜场顺序）或 `{"镜子ID": dni}`。场站的安全联锁独立于 APS，保持不变。

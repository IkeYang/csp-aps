# csp-aps

光热塔式电站（圆柱外置集热器）**设计仿真、镜场自动布置与实时瞄准策略（APS）**软件原型。

已按导师评审稿（2026-11-20，基线 0d9292d）逐条落实，对应关系见 [docs/REVIEW_RESPONSE.md](docs/REVIEW_RESPONSE.md)；模型细节见 [docs/MODEL.md](docs/MODEL.md)。

## 能做什么

| 模块 | 内容 |
| --- | --- |
| 在线 APS 控制引擎 | 每个控制周期输入时刻、逐镜实测 DNI、带有效时刻的预报快照、镜子可用状态、上一轮执行回执，输出每面镜子的瞄准坐标、散焦状态、方案有效时段和复核结果。<br>• 按管屏的通量上限<br>• 安全裕度、预报裕度<br>• 数据过期 / 缺失时回退<br>• 瞄准点平滑、可达性筛选<br>• 光斑响应缓存与热启动（热路径约 0.4 s / 1500 面镜） |
| 可行性复核 | 每个方案都在自适应细网格上用完整光斑复核：超限热点自动加入约束重解，仍不行就明确给出"不可执行"状态及热点位置、所在管屏、超限量、主要贡献镜 |
| 均匀受热 | 预热器考核区的面积加权二维 / 周向 / 高度 CV；支持 CV 上限和固定 λ 权重两种模式；输出受限功率、实际 CV、最低负荷和功率–均匀度曲线；小规模问题可用 SCIP 求精确最优 |
| 云影回放 | 随机云、云边扫过、云突然移开、DNI 延迟 / 丢失。对比不做 APS、只用当前 DNI、带预报三种策略：能量、超限时长（按区间统计）、端到端延迟 P50/P95、回退次数 |
| 全年能量 | 20 / 30 / 40 个 DNI 加权代表太阳位置（误差 < 0.5%）、高度角 × 方位角分箱、逐时；受限 APS 时按 DNI 分档；可读 EPW/CSV 气象文件；多进程并行 |
| 外层布置优化 | 径向交错 / 仿生螺旋参数化布局 → 可选中心瞄准或 APS 年收益搜索 → 前几名按通过通量与均匀度检查后的吸收能量复核排名 → 换位微调 → 镜数、边界、禁排区、最小镜距最终校验（布不满时报告缺额） |
| 光学校验 | 内部 MCRT：独立误差项、多随机种子的统计不确定度、光线数收敛表。SolTrace 对标：导出同场算例和 PySolTrace 驱动脚本。遮挡筛选：与暴力求交逐镜比对 |

## 安装

需要 Python ≥ 3.10。

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[gui,exact]"
```

`gui` 安装 Streamlit 和 plotly；`exact` 安装 SCIP（用于小规模精确基准，可选）。开发和测试用 `pip install -e ".[dev]"`。

Windows 本地开发安装：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\cspaps.exe gui
```

## 使用

### 图形界面

```bash
cspaps gui [cases/aksai_demo.yaml]
```

不传算例时默认打开阿克塞合成演示，使用阿克塞 2024 年逐小时 DNI 和可编辑的模拟设备 / 镜场输入。

不传算例时默认打开阿克塞合成演示。它使用阿克塞 2024 年逐小时 DNI，镜场、吸热器和控制参数是可编辑的设计输入。

| 工作区 | 内容 |
| --- | --- |
| 运行调度 | 首屏状态卡：时间戳、数据来源与新鲜度、策略、截获 / 吸收功率、最高通量及所在管屏、距上限余量、散焦镜数、指令状态（待复核 / 不可执行 / 已回退 / 已执行），窄窗下自动换行。<br>• 镜场 DNI 图、接收器展开图、时间轴在同一页，拖动时间轴同步更新<br>• 点击镜子看 ID、DNI、原瞄准点、计划瞄准点、散焦原因<br>• 点击接收器看该点的限值和主要贡献镜<br>• 可回放，也可导入实测 / 预报 DNI 和上一轮瞄准点 |
| 布局规划 | 依次为：① 场地与设备（场地图标注边界、禁排区、塔位、镜位）② 气象与采样 ③ 计算（可看进度、可取消）④ 方案对比：同一表格比较各方案的镜数、全年能量、峰值、采样误差、复核方式；应用前预览，应用后自动核对镜数、编号和坐标；导出布局与参数；对比两个方案的功率–均匀度曲线 |
| 光学校验 | 解析 / 追迹 / 差值三图（同一网格、同一色标），附引擎、光线数、种子和统计不确定度；SolTrace 对标导出；遮挡筛选复核 |
| 全部参数 / 运行记录 | 全部参数表单与 YAML 编辑；每次运行的独立记录，可回看结果，也可载入当时的输入 |

### 命令行

```bash
cspaps aps cases/aksai_demo.yaml --time "2024-03-19 15:30" --method greedy
cspaps annual cases/aksai_demo.yaml --method sun_bins --aiming greedy
cspaps optimize-layout cases/aksai_demo.yaml
cspaps layout          CASE                          # 生成镜场
cspaps snapshot        CASE --time "2025-06-21 13:40"  # 单时刻，中心瞄准
cspaps aps             CASE --time ... [--dni-map now.csv --forecast-dni-map max.csv --prev-aims last.csv]
cspaps realtime        CASE                          # 云影回放（场景、延迟、丢失在 YAML 中设置）
cspaps annual          CASE [--method sun_bins|sun_grid|hourly|representative_days] [--aiming center|greedy]
cspaps optimize-layout CASE                          # 布置优化 + 受限复核
cspaps uniformity      CASE --time ... [--eps 0.7 0.6 0.5] [--exact]
cspaps validate        CASE --time ... [--rays 3000 --seeds 3 --convergence 500 1000 2000]
cspaps soltrace-export CASE --time ...               # SolTrace 对标算例与驱动脚本
cspaps shading-check   CASE                          # 遮挡筛选与暴力求交对比
cspaps sunbins         CASE --check                  # 代表点误差：20/30/40 个及分箱，相对逐时
cspaps engine          CASE                          # 在线引擎：标准输入 / 输出的 JSON 行服务
```

- 每次运行写入 `results/<算例>/<任务>_<时间>/`，其中保存当时的输入（`inputs_case.yaml`）、`run.json` 和全部结果。
- 结果"不可执行"或布局校验不通过时，命令行退出码为 2。

### 接入电站控制循环

**Python 接口**：

```python
from cspaps import load_case
from cspaps.field import build_field
from cspaps.engine import APSEngine, ControlRequest, ForecastSnapshot, Receipt

case = load_case("plant.yaml")
engine = APSEngine(case, build_field(case))
resp = engine.step(ControlRequest(
    time=now, dni=dni_per_heliostat, dni_time=t_meas,
    forecasts=[ForecastSnapshot(t, dni_t) for t, dni_t in forecast],
    available=in_service, receipt=Receipt(last.plan_id, last.aim_azimuth, last.aim_z, last.active)))
resp.state            # "ready" | "fallback" | "infeasible"
resp.to_frame()       # id, active, aim_azimuth_deg, aim_z, aim_x, aim_y, defocus_reason
```

**JSON 行服务**：`cspaps engine plant.yaml`。每行一个请求，DNI 可以用列表（按镜场顺序）或 `{"镜子ID": dni}`。场站的安全联锁独立于 APS，保持不变。

### 输入

全部参数都在一个 YAML 文件里，`cases/example.yaml` 列出了每个参数并附中文注释（虚构的测试参数）。拼错的参数名会直接报错。

| 段 | 内容 |
| --- | --- |
| `site` / `sun` / `atmosphere` / `weather` | 站址、太阳形状与晴空 DNI、大气衰减、气象文件 |
| `receiver` | 圆柱集热器；管屏数、各管屏允许通量、吸收率、限值口径（入射 / 吸收）、实测 / 模型偏差系数、高度分布系数 |
| `heliostat` | 尺寸、反射率、清洁度、坡度误差、跟踪误差、镜面散射、聚焦方式 |
| `field` | 场地边界、禁排半径、布置生成器，或镜场坐标 CSV（`id,x,y,z`） |
| `aps` / `uniformity` / `engine` | 瞄准求解与复核；预热器考核区、ε、最低负荷；在线引擎周期、延迟、数据年龄、预报裕度、回退策略、转速 |
| `realtime` | 回放场景、时长、步长、预报、DNI 延迟 / 丢失 |
| `annual` / `layout_opt` | 全年采样（代表点数、分箱、DNI 分档、并行）；布置优化（镜数、参数范围、搜索与复核采样、换位、校验） |
| `mcrt` | 光线数、种子数、跟踪误差模式 |

## 示例结果

以下结果均来自 `cases/example.yaml`（虚构参数，不对应真实电站）：北纬 40°，晴空；集热器直径 7 m、高 8 m，12 块管屏，通量上限 1000 kW/m²，安全裕度 5%；1532 面 8×8 m 定日镜；候选瞄准点为 3 个方位 × 9 层高度。在 4 核机器上运行，峰值均为细网格复核值。

### 单时刻 APS（夏至 13:40）

| 方案 | 状态 | 截获 / 吸收功率 (MW) | 复核峰值 (kW/m²) | 二维 / 周向 / 高度 CV | 耗时 |
| --- | --- | --- | --- | --- | --- |
| 全部瞄准中心 | 不可执行（1 号管屏超限 193 kW/m²） | 69.24 / 65.78 | 1192.6 | 0.854 / 0.195 / 0.820 | — |
| 贪心 APS | 可行 | 69.13 / 65.67 | 888.4（12 号管屏） | 0.725 / 0.142 / 0.701 | 4.7 s（冷启动，其中构建光斑响应 3.0 s） |

### 均匀受热（同一时刻，考核区为整个圆柱面）

| ε（允许的二维 CV） | 0.72 | 0.64 | 0.56 | 0.48 |
| --- | --- | --- | --- | --- |
| 吸收功率 (MW) | 65.75 | 65.68 | 65.54 | 65.21 |

- 二维 CV 从 0.725 降到 0.48，吸收功率只少 0.8%。
- 上下边缘带功率上界：取 L = 贪心解功率的 99.5%，u ≤ 8.02%，二维 CV 下界 0.392。在这个候选集下 CV ≤ 0.39 不可达，与导师给的读数（8.05%，约 0.39）一致。

### 云影回放（在线引擎驱动，60 s 刷新，方案延迟一个周期生效）

| 场景 | 策略 | 能量 (MWh) | 最大复核峰值 (kW/m²) | 超限时长 | 每轮调整镜数 | 引擎延迟 P50 / P95 |
| --- | --- | --- | --- | --- | --- | --- |
| 随机云 20 分钟 | 不做 APS | 22.08 | 1199 | 20 分钟 | 0 | — |
| | APS（仅当前 DNI） | 22.05 | 1095 | 1 分钟 | 30 | 0.42 / 3.3 s |
| | APS + DNI 预报 | 22.05 | 893 | 0 | 7 | 0.40 / 3.0 s |
| 云突然移开（10 分钟） | APS（仅当前 DNI） | 7.95 | 1071 | 1 分钟 | 66 | 0.85 / 3.2 s |
| | APS + DNI 预报 | 7.93 | 905 | 0（1 次回退） | 90 | 2.2 / 3.3 s |
| DNI 中断 3 分钟（10 分钟） | APS（仅当前 DNI） | 10.66 | 1104 | 1 分钟（3 次回退） | 70 | 0.68 / 3.2 s |
| | APS + DNI 预报 | 10.66 | 880 | 0（3 次回退） | 7 | 0.47 / 3.2 s |
| 云边扫过（10 分钟） | 两种 APS | 6.63 | 867 | 0 | 80 | 0.39 / 3.3 s |

- P95 主要来自太阳移动后重建光斑响应（约每两分钟一次）；复用响应的热路径约 0.4 s。
- 3 分钟回归示例：只用当前 DNI 999.6 kW/m²，带预报 868.4 kW/m²，不做 APS 时全程 180 s 超限。

| --- | --- | --- | --- | --- | --- |
| 逐时，中心瞄准（基准） | 4072 | 206,710 | — | — | 51 s |
| 20 个代表点，中心瞄准 | 20 | 208,224 | +0.73% | — | 0.7 s |
| 30 个代表点，中心瞄准 | 30 | 207,543 | +0.40% | 2537 | 1.2 s |
| 40 个代表点，中心瞄准 | 40 | 207,227 | +0.25% | — | 1.6 s |
| 高度角 × 方位角分箱 | 65 | 207,127 | +0.20% | — | 3.0 s |
| 30 个代表点，受限 APS | 30 | 207,173 | — | 0 | 98 s |

- 按 DNI 分档后受限 APS 的年能量低 0.23%：合并强弱工况会高估受限能量，与导师指出的方向一致。

### 光学校验

**MCRT**（贪心 APS 方案，每面镜子 3000 条光线 × 3 个种子）：

- 截获功率：解析比追迹低 0.97%（69.13 vs 69.81 MW，标准误 0.002 MW）；
- 通量图：NRMSE 0.026，相关系数 0.9994；
- 峰值：解析 888 kW/m²，追迹平均图 910 kW/m²（单次运行 919 ± 1.9）。

峰值随光线数的收敛：

| 每镜光线数 | 500 | 1000 | 2000 | 4000 |
| --- | --- | --- | --- | --- |
| 追迹峰值 (kW/m²) | 945 | 919 | 915 | 911 |

峰值收敛到约 911 kW/m²，解析模型低约 2.5%，原因是 HFLCAL 的圆高斯近似。各环节效率差：余弦、反射、阴影都为 0，遮挡 −0.001，截断 −0.008。

**遮挡筛选复核**（与全对暴力求交逐镜比较）：

| 工况 | 镜数 | 太阳高度角 | 漏判 | 筛选 / 暴力耗时 |
| --- | --- | --- | --- | --- |
| 低太阳、近场 | 470 | 5° | 0 | 0.04 / 3.1 s |
| 低太阳、远场 | 339 | 5° | 0 | 0.01 / 1.7 s |
| 低太阳、密集布局 | 1087 | 5° | 0 | 0.16 / 16.3 s |
| 正午、边缘瞄准 | 470 | 46° | 0 | 0.006 / 2.9 s |

### 外层布置优化（固定 1200 面镜）

- **搜索**：差分进化 6 代加 4 轮局部微调，共 134 次布局评价，采样为 30 个代表点、中心瞄准。
- **复核**：前 3 名方案改用 40 个代表点 × 3 档 DNI，并启用受限 APS；同时做逐时全年中心瞄准对比。
- **换位微调**：第 1 轮换 36 面，+27.8 MWh，接受；第 2 轮 −2.6 MWh，拒绝。
- **最终校验**：通过（最小镜距 13.27 m，要求 12.45 m；边界内；禁排区外）。
- **用时**：约 34 分钟（4 进程）。

| 搜索排名 → 最终排名 | 周向间距系数 | 搜索能量（30 点，中心瞄准） | 逐时中心瞄准 | 搜索采样误差 | 受限 APS 年能量（120 状态） | 中心瞄准超限小时 |
| --- | --- | --- | --- | --- | --- | --- |
| 2 → 1 | 1.140 | 173,356 | 172,373 | +0.57% | 172,285（换位后 172,313） | 2887 |
| 3 → 2 | 1.115 | 173,354 | 172,374 | +0.57% | 172,233 | 2887 |
| 1 → 3 | 1.090 | 173,358 | 172,338 | +0.59% | 172,215 | 2887 |

表中能量单位均为 MWh。

- 搜索阶段排第 1 的方案在受限复核后降到第 3。三者相差不到 0.04%，属于差距很小、必须复核的情形。
- 受限复核中有 2–9 个工况的复核结果为"可行但裕度不足"：峰值在 950–952 kW/m² 之间，未超过 1000 的限值，但用掉了部分 5% 的安全裕度。

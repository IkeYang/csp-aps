## P0-01 修正通量可行性判定

**问题复现**：评审给的算例为镜心 (0, 80, 5) m，6 月 21 日 13:40，关闭阴影遮挡，只保留中心候选点，限值 10 kW/m²。12×8 网格报 4.18 kW/m²（可行），360×160 网格复算为 19.49 kW/m²。本程序复现出相同的两个数值（测试 `test_p0_01_coarse_grid_misses_the_peak`）。

**处理**：

- 新增 `verify.py`：网格间距不大于最窄光斑 σ 的 1/3，用约束 DNI 完整叠加全部光斑（不截尾），在最热的局部极大点周围再用 9×9 子网格精化。
- 每个点与该点所在管屏的限值比较；超限的局部极大点加入约束集后重新求解，即约束生成（`aps.solve`）。
- 求解网格也会按最窄光斑自动加密。

**最终状态**：`ok` / `margin_reduced` / `infeasible`。优化器、命令行（不可执行时退出码 2）和界面（指令状态显示"不可执行"）使用同一个状态，并记录热点坐标、所在管屏、超限量和主要贡献镜。

**验收**：

- 原中心瞄准解被拦截：状态 `infeasible`，复核峰值 19.5 kW/m²，超限约 9.5 kW/m²。
- 贪心法给出唯一可行解（散焦）。
- k 因子法无法散焦，明确返回 `infeasible`。
- 测试：`test_p0_01_centre_aim_is_intercepted`、`test_p0_01_verified_peak_matches_fine_grid`。

## P0-02 修正导出布局重新载入丢镜

**原因**：CSV 只保留 3 位小数，恰好位于禁排边界上的镜子舍入后落到边界以内，重新载入时被过滤。

**处理**：

- 镜场带固定编号；布局 CSV 改为 `id,x,y,z`，精确到微米；
- 边界判断统一使用 `field.site_mask`，留 1 mm 容差；
- 被过滤的镜子写入 `Field.dropped`（编号、坐标、原因），命令行、界面和结果文件都会报告。

**验收**：

- 优化得到 120 面，导出、应用、重新载入后仍为 120 面，编号和坐标逐项一致；
- 界面"确认应用"后会自动核对并显示结果；
- 测试：`test_p0_02_*`、`test_gui_walkthrough`。

## P0-03 修正云影回放时间统计

**处理**：采样时刻为 0、步长、2×步长……以及回放终点；第 k 个采样代表区间 [t_k, t_k+1)。能量 = Σ 功率 × 区间长度，超限时长按区间累加；结果中注明这一统计口径（`over_limit_basis`）。

**验收**：

- 恒定 60 MW、60 s 步长：3 分钟回放累计 3.0 MWh，150 s 回放累计 2.5 MWh（区间为 60、60、30 s）；
- 全程超限时，超限时长等于回放时长；
- 测试：`test_p0_03_*`。

## P1-01 将光斑计算移出每轮 DNI 更新

**处理**：

- `aps.ResponseSet` 缓存与 DNI 无关的几何、遮挡、截断效率和稀疏的单位 DNI 响应。每轮只做逐行 DNI 缩放（`make_problem`）。
- 太阳移动超过 `response_refresh_deg`（默认 0.3°）才重建。最终复核总是用当前太阳几何（重算遮挡）；复核不通过，就生成约束并修复。
- 热启动从上一轮已执行方案出发：先移走造成超限的镜子，再优先重算 DNI 变化大、靠近热点、处于散焦或刚恢复可用的镜子。
- 贪心法保留为在线基线；小规模问题用 MILP 求精确解和 LP 上界，以衡量差距（`test_milp_and_lp_bound_on_tiny_problem`）。

**验收**：端到端计时包含输入检查、响应构建或复用、求解、复核和输出，回放中逐轮记录。延迟 P50/P95、冷启动次数、超时次数、每轮调整镜数见文末数值记录。控制周期和算力预算以场站设备为准，可在 `engine` 段配置。

**未做**：镜子分区并行求解。现有热路径约 0.4 s，暂不需要。

## P1-02 支持带时间戳的当前和预测 DNI

**接口**：`engine.APSEngine.step(ControlRequest)`，也可以用 `cspaps engine` 以 JSON 行方式持续运行。

- **输入**：时刻、太阳角（可选，否则按站址计算）、逐镜当前 DNI 及其时间戳、带有效时刻的预报快照、镜子可用状态、上一轮执行回执。
- **输出**：镜子 ID、瞄准坐标、散焦状态及原因、方案有效时段、复核结果、状态（ready / fallback / infeasible）及原因、各环节耗时。
- 镜子 ID 在布局、DNI、指令和回执之间保持一致；DNI 也可以按 ID 传入。

**数据检查**：

- 数据新鲜度：超过 `max_dni_age_s` 即视为过期；
- 预报必须覆盖 [t + 延迟, t + 延迟 + 周期]；
- 预报误差：乘以 `forecast_margin` 留出裕度；
- 可达性：按镜面转速 ×（延迟 + 周期）筛选候选点。

逐镜最大 DNI 作为保守基线保留：无预报时默认用晴空 DNI（`no_forecast_policy`）。

**回放场景**：

- 移动云边（`moving_edge`）；
- 云突然移开（`sudden_clear`）；
- DNI 延迟（`dni_delay_s`）或丢失（`dni_dropout_s`）。

逐轮记录可执行性、超限幅度、回退状态及原因。数据过期、求解超时或复核失败时进入配置的保守策略（`fallback`），并在状态中标明。

**测试**：`test_engine_*`、`test_replay_*`。

## P1-03 引入按管屏的热流限制和反馈

**配置**：管屏数、起始方位、各管屏允许通量、各管屏吸收率、限值口径（入射或吸收）、高度分布系数、实测 / 模型偏差系数（运行反馈接口）。

**统一换算**：所有比较都先换算成"允许的模型入射通量"（`receiver.incident_limit_w_m2`）。

**输出**：截获功率和吸收功率分别给出；同时给出最高通量、所在管屏和距上限余量。

**验收**：两个管屏、允许通量不同（500 / 150 kW/m²）。细网格上各管屏都不超过自己的限值，北侧管屏用到了高于 150 的限值；不做 APS 时南侧管屏超限（`test_two_panels_with_different_limits`）。

**现场接入**：按评审建议，以历史回放、影子运行和实测反馈验证为主线；偏差系数是反馈接口。APS 之外的独立安全联锁不受影响。

## P1-04 让用户选择全年评估方式

## P1-05 保证布局约束和结果可追溯

**取消**：长任务可以取消，取消后对已找到的方案照常复核。

## P1-07 布局规划工作区

**流程**：① 场地与设备 → ② 气象与采样 → ③ 计算（可看进度、可取消）→ ④ 方案对比与应用。

- **场地图**：标注边界、禁排区、塔位、镜位和候选镜位。
- **候选表**：同一张表比较镜数、全年能量（搜索 / 复核 / 逐时 / 受限 APS）、采样误差、峰值、复核方式和排名变化；切换候选方案时，图和表保持一致。
- **应用**：应用前预览坐标系和镜数；应用后自动核对（P0-02）；可导出同一份布局 CSV 和参数 YAML。
- **均匀度对比**：可对比两个方案的功率–均匀度曲线（P1-10 验收）。
- **运行记录**：可回看历史方案，也可载入当时的输入。

## P1-08 定义考核面与运行工况

**配置**：预热器考核区 H 由管屏和高度范围指定；暗区也计入面积。可按管屏设置吸收率；均匀度用吸收热流评价。

**指标**：二维 CV（面积加权）、周向 CV（先按高度平均）、高度 CV（先按周向平均）。

**带均匀度约束的 APS**：在通量限值、CV ≤ ε 和最低负荷约束下最大化吸收功率（`uniformity.solve_uniform`，用拉格朗日局部搜索加权重二分）。达不到最低负荷时记为 `below_min_load`，按停机单独记录。

**精确基准**：小镜场用 SCIP 求混合整数二阶锥规划，状态为已证最优 / 除停机外不可行 / 限时可行。测试验证了放宽 ε 时，被证明的最优功率单调不减（`test_exact_benchmark_monotone`）。

**ε 扫描**：`cspaps uniformity`、界面的规划页 ④，输出功率–均匀度曲线并标注各点状态。

**未做**：管壁温差指标需要用壁温、流量和入口温度标定热模型，目前只有接口（偏差系数），没有热模型。

## P1-09 计算上下边缘的功率上界

按评审公式实现 `uniformity.edge_band_bound`：

- 带内功率用精确的高度带截断效率计算，不依赖网格；
- 包含散焦选项；
- 对 λ 先在对数网格上搜索，再用有界一维最小化精化。

输出保存功率下限、区域边界、面积占比、上界 u、λ、二维 CV 下界和光学假设。规划页 / `cspaps uniformity` 中，只有已证下界高于目标 ε 时才标注"不可达"。

**验收**（示例，L = 贪心解功率的 99.5%，默认候选集）：数值见数值记录，与评审读数（u ≤ 8.05%，CV 下界约 0.39）一致。

## P1-10 联合选择镜位与瞄准点

- **排名依据**：复核阶段按受限全年能量重排；受限能量由每个工况的 APS 可执行功率（细网格复核）乘以时长权重得到。
- **换位微调**：把 APS 全年收益最低的镜子，换成未使用的最佳候选位置；以重新求解 APS 后的全场年能量增量决定取舍。
- **均匀度对比**：规划页可在同一 ε 序列、同一时刻下叠加两个方案的功率–均匀度曲线。

**未做**：小场的"选址 + 瞄准"联合整数优化及其上界，以及连续小幅移动镜位。

## P2-02 入射阴影与反射遮挡加速

新增全对暴力求交（`shading_blocking_bruteforce`），与现有的"KD 树 + 走廊"筛选在评审要求的四种工况下逐镜比对：低太阳高度角、密集镜位、远端镜、边缘瞄准（`cspaps shading-check`、`test_screening_matches_bruteforce`）。

## P2-03 光斑展宽和独立追迹

**独立的误差参数**：

- 太阳形状；
- 镜面坡度误差；
- 镜面散射（`specular_error_mrad`，解析与 MCRT 同时支持）；
- 跟踪误差：可按每条光线随机，也可按每面镜子固定偏置（`mcrt.tracking_mode`）。

**SolTrace 对标**：`cspaps soltrace-export` 导出同场几何、太阳位置、逐镜姿态（法向、焦距、尺寸、是否工作）、统一误差定义（法向误差 = sqrt(坡度² + 跟踪²)）、两侧都不计大气衰减，以及同一网格上的解析通量图和内部 MCRT 结果；同时附上 PySolTrace 驱动脚本。

驱动脚本依据 SolTrace v3.4.0 的 `pysoltrace.py` 接口编写，建立相同场景（球面镜、吸收圆柱接收器、塔身吸收体），把命中点统计到相同网格，输出功率、峰值、热点格、NRMSE、相关系数、种子和耗时。

**限制**：在本开发环境中编译并运行 SolTrace 被权限策略拦下，所以还没有 SolTrace 实测结果。请在装有 SolTrace v3.4.0 的电脑上运行：

```bash
python run_pysoltrace.py benchmark_case.json --pysoltrace <SolTrace>/app/deploy/api
```

**内部对照**：示例 APS 解的追迹统计和收敛表见数值记录。评审注意到峰值相差约 5%（解析 879.6、追迹 923.8 kW/m²）。追迹峰值是噪声图的最大值，本身偏高，所以现在报告平均图峰值及其标准误，并给出光线数收敛表。

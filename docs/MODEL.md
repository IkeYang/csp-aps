# 模型与算法说明

本文说明 csp-aps 每个计算环节用的模型、公式和近似，以及代码位置。坐标系：x = 东，y = 北，z = 上（m），原点在塔底；方位角按罗盘计（北 = 0°，东 = 90°，顺时针）。

## 0.9 年度计算加速：控制变量、复用、贝叶斯搜索、通量价格换位、并行

年度价值 V(L) = Σ_s h_s (P_s − λ_L U_s)（0.5.4 节）的定义不变。0.9 改的是怎样更快、更准地算它，以及怎样用它找布局。五项都可单独开关，默认值下同一布局、同一工况集、同一内层设置的 P_s、U_s 仍逐位可复算。

### 0.9.1 控制变量修正（`layout_value.control_variate`，`layout_opt.control_variate`）

代表工况 s 代表全年里被聚到它的那些小时 t ∈ T_s（工况集现在记录每个小时归到哪个工况：`ScenarioSet.assignment`，随工况集保存在 `hourly_members.csv`）。正式值用代表状态的 J(s) 乘小时数 h_s，误差来自“代表状态 ≠ 成员小时的平均”。用一个便宜、与 J 高度相关的模型 C（中心瞄准、不算热流图，每面镜读该小时地图上的 DNI）估计这个误差：

```
f_s = Σ_{t∈T_s} w_t C(t) / (h_s C(s))          （分工况的比率估计）
V_cv = Σ_s h_s J_s f_s,   E_cv、Π_cv 同理
```

假设代表状态在贵模型里的相对误差与在便宜模型里相同。成员上 C 线性时 f_s = 1；f_s 截在 [0.5, 2]。所有成员小时的 C 之和就是全年逐时的中心瞄准能量（`test_control_variate_factors_follow_the_cheap_model`）。代价：一次全年逐时中心瞄准，不解 APS。正式 V 不变，`layout_opt.rank_by: value_cv` 时按修正值排名，`value`（默认）时只报告。逐时 APS 参考值（`scripts/validate_annual_estimators.py`）给出两种估计的误差，见 0.9.6。

### 0.9.2 复用（`layout_opt.inner_reuse`，`scenarios.shared_directions`）

- **同方向共用光斑响应**（`responses`，默认）。响应集 R（每面镜每个候选瞄准点的单位 DNI 热流）只依赖太阳方向，不依赖 DNI。同一方向的工况只建一次 R，每个工况用它的深拷贝求解，方案与独立求解逐位相同（`test_response_reuse_and_batches_are_bit_identical`）。
- **DNI 齐次性**（`full`）。DNI 整体乘 f ≤ 1 时，P、U 都是一次齐次：P(f·D) = f·P(D)。若求解中通量限值从未排除过任何候选（贪心与均匀性调整都记录 `flux_limited = 0`，第一轮细网格复核即通过，没有联合姿态被通量否决），较低 DNI 下所有比较的排序不变，决策相同，于是直接沿用最高 DNI 的方案，按 f 缩放 P、U，再做一次细网格复核。测试核对了冷启动在各 DNI 档的决策确实相同，缩放后的 P、U 与 f 倍源方案相差 < 1e-12。`full` 还沿太阳轨迹把上一个工况的方案作为热启动（全年切成固定的 8 条链，与核数无关），所以与独立冷启动可能因并列取舍不同而有微小差别，但对同一组工况和设置逐位确定。
- **共用太阳方向**（`shared_directions`）。不按地图、DNI 分档各自聚类，而是全年统一聚出 K / 地图数 个方向，每个 (方向, 地图, DNI 档) 再按成员小时聚合 DNI（每张地图的 DNI 能量守恒）。这样一个方向的响应集服务它所有的地图和 DNI 档，齐次性复用也才有机会触发。

### 0.9.3 分级保真的贝叶斯布局搜索（`bayes.py`，`layout_opt.search_method: bayes`）

生成器只有 3–7 个参数（径向、周向间距，径向增长，可选北 / 东 / 南 / 西四个扇区稀疏系数），每次评价很贵，适合贝叶斯优化。目标直接取低保真的正式 V：`bayes_scenarios`（默认 8）个工况、每个工况 1 次联合姿态试探、不做松弛取整、`full` 复用，而不是中心瞄准初筛（哈密均匀 DNI 研究里三个中心瞄准初筛布局在正式口径下都不如初始镜场，见 README 结论 2）。

```
模型：  零均值高斯过程，Matern 5/2 核，每维一个长度尺度，噪声与长度尺度按最大边际似然（L-BFGS，4 次重启）
初始：  Sobol 序列 2d + 2 个点（d = 参数维数），可由 bayes_initial 指定
采集：  期望改进 EI(x) = (μ − y*) Φ(z) + σ φ(z)，z = (μ − y*)/σ；4096 个 Sobol 候选 + 5 次局部 L-BFGS
批量：  q = min(4, ⌈核数 / 工况数⌉) 个点一批（常数说谎法：已提出的点暂记当前最优值），一批的所有（布局, 工况）一起进进程池
```

最好的几个布局再进入正常的复核和全精度正式排名（高保真）。**分扇区镜距**（`layout_opt.sector_spacing`，`field.sector_thinning`）：每圈按 m(φ) 保留约每 m 个位置中的一个，m 在北、东、南、西四个系数之间按与各方向夹角的 cos² 插值（只在 90° 以内起作用）；只删位置，所以最小镜距不变。

### 0.9.4 通量价格指导换位（`certify.aps_upper_bound(price_mask=…)`，`layout_value.dual_prices`，`layout_opt.swap_pricing: dual`）

问题一的对偶上界（0.1 节）对拉格朗日函数做投影次梯度：ν_p ≥ 0 是约束点 p 的通量限值乘子，即该吸热器网格的“拥挤价格”；均匀性项在当前方案处线性化成权重 w_o（考核区每个网格一个）。对布局之外的候选镜位 j（按“已加入”计算它被布局中各镜的遮挡，`build_response(blockers=…)`），在上界最好一轮的乘子下

```
G_j = max(0, max_k [ c_jk + (μ ε + ρ) h_jk − DNI_j · R_jk · (w_o + ν / lim) ])
```

c_jk 是 j 瞄候选点 k 的吸收功率，R_jk 是它在各约束点的单位 DNI 热流。拉格朗日函数是凹的、线性化点处 x_j = 0，由弱对偶：

```
J*_s(L ∪ {j}) ≤ UB_s(L) + G_js            （j 不遮挡布局中的镜子时）
```

与穷举最优比对通过（`test_flux_prices_bound_the_value_of_an_added_heliostat`，功率与两种 λ 各 2 个镜位）。去掉镜子 i 的损失 D_is = J_s(方案) − J_s(方案去掉 i，其余瞄准不变)，在模型里精确计算（`certify.removal_losses`；去掉镜子不会违反通量限值，被它遮挡的邻镜不加回）。年度上 gain_j = Σ_s h_s G_js，loss_i = Σ_s h_s D_is；换位按 gain 从高到低、loss 从低到高配对，只取 gain − loss > 0 的对，预测增益是一阶估计，重新逐工况求解后 V 提高才接受，否则减半重试。由上式，单独加入 j 的增益不超过 gain_j + Σ_s h_s (UB_s − J_s)，这个差额随结果一起报告（`bound_gap_mwh`）。

与原来的能量定价（APS 年吸热最少的镜子换出、中心瞄准年能量最高的空闲镜位换入）比，能量定价看不到吸热器拥挤：中心瞄准能量高的镜位往往把光斑加在已经顶到限值的网格上。实测见 0.9.6。

### 0.9.5 并行与 GPU（`layout_value.evaluate_layout_values`，`backend.py`）

- 多个布局的全部（布局, 工况链）放进一个进程池，正式排名、换位和贝叶斯批量评价都用它，核数不再受单个布局的工况数限制。结果与逐个布局计算逐位相同。
- `CSPAPS_GPU=1` 且装有 CuPy 时，`optics.footprints_at`（候选点响应、细网格复核、热流图都经过它）在元素数 ≥ `CSPAPS_GPU_MIN`（默认 200 万）时在 GPU 上算；各工作进程按进程号分到 `CSPAPS_GPU_DEVICES` 列出的卡上。指数在两条路径上都按 float32 计算，GPU 结果与 CPU 相差在 float32 舍入以内，但不逐位相同，所以每个年度价值记录所用后端（`tags.backend`），不要混用两种后端的结果做逐位比较。没有 CuPy 或没有显卡时自动走 CPU，结果与以前逐位相同。

## 0.7.2 塔影的几何与光斑在吸热面上的大小

**塔影的遮挡体**（`shading.shadow_cylinders`、`shading.ray_hits_structure`）。两段同轴竖直圆柱，所有尺寸都取自算例：

```
塔身：   半径 r_t = receiver.tower_diameter / 2（不填 = 吸热器半径），   z ∈ [0, H_t]，   H_t = receiver.tower_height（不填 = 吸热器底部 z_b）
吸热器： 半径 R = receiver.diameter / 2，                               z ∈ [z_b, z_t]，  z_b, z_t = 中心高 ∓ 高度 / 2
```

塔身直径填 0 时不计塔影。镜面采样点 p 沿太阳方向 s 的射线 p + λ s（λ > 0）与任一段相交（侧面或顶、底面），该点就在塔影里。镜面遮挡、MCRT、在线引擎、平面图与 SolTrace 导出都用这一个函数。塔身直径不填、塔高不填时，两段合成一段吸热器半径、到吸热器顶的圆柱，与 0.7.1 逐位相同（`test_default_tower_reproduces_the_single_cylinder`）。

**平面图上的塔影轮廓**（`gui_plots.tower_shadow_outline`）。在高度 z_p 的水平面上，一段半径 r、高度 [z_0, z_1] 的圆柱，其高度 z 处的截面圆投到平面上，圆心在塔轴下风向 (z − z_p) / tan h 处（h 为太阳高度角）。z 取遍 [max(z_0, z_p), z_1]，扫出一个两端为半圆的条带：

```
近端 d_0 = (max(z_0, z_p) − z_p) / tan h，   远端 d_1 = (z_1 − z_p) / tan h，   宽 2r
```

两段圆柱各画一个条带，取其并集。z_p 取镜子自己的高度：镜场坐标 z 的中位数；没有镜场时取 `heliostat.pivot_height`。导入的布局有自己的 z 时，轮廓画在那个高度。测试 `test_shadow_outline_matches_the_ray_test` 在三个太阳位置、三组塔径与塔高、两个平面高度上逐点核对，轮廓内的点与射线判定一致。

**光斑在吸热面上的大小**（`optics.surface_spot`）。HFLCAL 光斑在光束截面上是标准差 σ 的圆高斯（σ 含太阳形状、镜面斜率、跟踪与镜面散射误差、斜距处的像散）。设瞄准点在罗盘方位 φ，取切平面坐标

```
e_φ = (cos φ, −sin φ, 0)（方位增大的方向），  e_z = (0, 0, 1)，  外法向 n = (sin φ, cos φ, 0)
```

吸热面上的偏移 w = u e_φ + v e_z 在光束截面上的距离是 |w − (w·t) t|，t 为光束方向。记 a = (t·e_φ, t·e_z)，热流随 exp(−wᵀ(I − a aᵀ)w / 2σ²) 衰减，所以光斑在吸热面上的协方差为

```
Σ = σ² (I − a aᵀ)⁻¹ = σ² (I + a aᵀ / cos² i)，   cos i = |t·n| = sqrt(1 − |a|²)
```

圆光斑沿 a 的方向被拉长 1 / cos i 倍。k-σ 椭圆的半轴为 kσ / cos i 和 kσ，k = 2 时含约 1 − e⁻² ≈ 86% 的光能。在二维展开图上，周向偏移 u 换算为方位角 u / R（弧度）。测试 `test_surface_spot_matches_the_numerical_footprint` 用模型自己的光斑函数 `footprints_at` 在切平面上做数值积分，二阶矩与 Σ 一致（相对误差 < 0.2%）。

## 0.7.1 塔影保持瞄准与背景并行

塔影的物理遮挡保留在式 (2)：它仍然削减镜面的反射功率。新增的 `tower_fraction[i]` 是从第 i 面镜按当前太阳方向向太阳作反向射线，在每个镜面采样点上检测有限高度圆柱塔得到的遮挡比例。若本面镜射向吸热器的全部离散瞄准候选都被塔完全遮挡，且其原瞄准候选也被完全遮挡，则两种动作的当前热目标相同。主目标 `P_abs - λU` 不加虚构的运动代价；只在精确热目标相同时，按字典序最小化新增散焦，再最小化离散候选瞄准变化。这样塔影导致的零功率不会单独成为散焦理由，而候选姿态中有部分光路可达时仍由正常热目标选择。执行器上一次目标落在离散候选集以外时，在线引擎会将对安全无影响的变更还原为上次实际下发的目标，再按实际镜位和邻镜几何作安全及均匀度复核。

启用预热器最低负荷时，若全部可行候选方案因最低负荷而不成立，只有 `aps.allow_defocus` 为真才关闭其余镜子；若关为假，软件报告不可行并保留瞄准状态，不发散焦指令。通量超限修复继续只对实际造成超限且可移动的供热镜子采取措施。全塔影或部分塔影标记和逐镜遮挡比例同时用于工作平面图、三维示意、工况查看、云影对比和实时回放。图中投影多边形是镜轴高度的圆柱塔影，精确的逐镜比例来自该镜实际候选姿态的离散镜面采样，两者不混为一项预测测量。

Streamlit 热重载可在一个进程内重新执行 Python 模块，使运行任务持有的 `_Objective` 类对象与 pickle 解析到的同名类对象不同。在多进程派发时，即使可见类名一致也无法序列化。`parallel.pool` 因此只在后台应用线程中采用线程池，普通命令行和测试主线程仍使用原来的进程池。线程任务按值保存每次评价记录；差分进化在多工作线程时使用 deferred 更新。

## 0.6 改进方案：计算口径、求解器证据与首次使用验收

本节对应 [改进方案](APS-IMPROVEMENT-PLAN.md)。前四小节改变排名口径，后四小节是算法升级的证据。

### 0.6.1 代表工况的小时：实际小时与时间平均 DNI

一簇逐时记录 t ∈ s（时长 w_t、DNI G_t）合成一个工况时，能量守恒只约束乘积 G_s h_s = Σ G_t w_t，G_s 与 h_s 各自怎样取是口径问题。0.5 取能量加权 G_s = Σ G_t² w_t / Σ G_t w_t，小时数 h_s = Σ G_t w_t / G_s 是“等效满辐照小时”，比实际小时少：阿克塞 20 个工况合计 2,800.62 等效小时，实际 4,028 小时。吸收功率 P 对 DNI 不是线性的（通量限值、散焦、均匀性项、最低负荷），用偏高的 DNI 乘偏少的小时，会系统地放大限值的作用。

0.6 默认 `time_mean`：G_s 取簇内时间平均，h_s 取实际小时 Σ w_t。两种口径的 DNI 年能量相同（上式），E = Σ h_s P_s 读作“实际年吸热量”。

两种口径什么时候给出不同的 V：把一个工况所有镜子的 DNI 同乘 c > 0，P 与 U 都乘 c，目标 P − λU 也乘 c，所以只要通量限值和最低负荷不起作用，最优方案不变，h_s P_s(G_s) = (h_s G_s) P_s(1) 只取决于这簇的 DNI 能量，两种口径的 V 逐位相同（贪心、联合姿态搜索的比较都按同一比例缩放，启发式解也相同）。三个演示站址的吸热器峰值不到上限的 20%，阿克塞 20 个工况在两种口径下 V 都是 28,976.2 MWhₜₕ，只有报告的小时数从 2,772.8（等效）变为 4,028（实际）。限值或最低负荷起作用时两者才不同：能量加权口径用偏高的 DNI 乘偏少的小时，会放大限值造成的散焦与损失。工况表同时记录 `actual_hours`（实际小时）与 `hours`（V 的权重），能量权重另存（`sampling_record` 的 `weight_hours`）。导入的工况清单按文件里的小时数计。测试：`test_actual_hours_and_energy_weight_are_recorded_separately`。

### 0.6.2 严格安全裕度

可行的含义只有一个：完整光斑在细网格上的峰值 ≤ (1 − m) × 限值，即复核状态为 `ok`。0.5 把 `margin_reduced`（峰值在 (1 − m)·限值 与 限值 之间）也计为可行；粗网格还会低估峰值。0.6 的规则：

- 年度价值、APS 页的结论与“可以执行”判断只认 `ok`（`simulate._annual_state` 的中心瞄准路径也做细网格复核；纯能量研究可设 `check_flux=False`，结果标注“未校核通量”）。
- 求解器最后一步是**从当前方案出发的修复**（`aps.solve`）：均匀性调整或重新求解可能把峰值推过安全裕度（仍在限值之下）；修复只移动或散焦给超限点供热的镜子，直到复核为 `ok`。没有这一步时，联合姿态复核只能退回到很差的可行方案。测试算例（346 面镜）在 0.6.6 的“逼近热流限制”工况上，修复前方案只剩 18 面镜（0.47 MW），修复后 346 面全部工作（9.36 MW，峰值为限值的 0.87）。测试：`test_near_limit_plan_keeps_its_power_after_the_final_repair`、`test_single_mirror_boundary_case_uses_the_margin_everywhere`。

### 0.6.3 一个偏好 λ

默认 λ_APS = λ_L = λ（`layout_opt.aps_weight: null`）：运行时怎样瞄准与评价时怎样排名用同一个“更重视吸热量 ↔ 更重视受热均匀”的偏好，界面只有一个滑块。此时 V = Σ_s h_s J_s，是各工况内层最优值的加权和。高级设置可以分开（0.5.4 的性质 1、3 不变）。测试：`test_shared_lambda_is_the_default`。

### 0.6.4 覆盖率、排名待定与价值区间

取消或中断时，已完成的工况保留，其余记为 `not_solved`。总表给出 `coverage`（已求解工况的比例）与 `hours_coverage`；覆盖率不足 1 的布局 `ranking_status = pending`，不参与排名，界面显示“排名待定”和已完成部分的得分。

λ_L = λ_APS 时，每个工况的内层值满足 J_s(found) ≤ J*_s ≤ UB_s（UB_s 是候选集上的有效上界；已证不可行取 0）。于是

```
Σ_s h_s J_s(found)  ≤  V*(L)  ≤  Σ_s h_s UB_s
```

V*(L) 是同一模型下（同一候选集、网格、裕度）该布局的最优年度价值。两套布局的区间若重叠（另一布局的上界高于第一名的得分），增加内层预算后排名可能改变，界面提示“优先增加预算”（`compare_values` 的 `interval_overlaps_leader`）。权重不等时区间不成立，只报告得分。测试：`test_value_interval_brackets_the_found_value`。

### 0.6.5 子场分解（`aps.method: subfield`）

按每面镜在吸热器上的中心瞄准方位把镜场分成 S 个扇区（`aps.subfield_sectors`，默认 4）。扇区 k 在每个约束点 p 上分得限值的份额

```
s_k(p) = Σ_{i∈k} max_c F_{i,c}(p) / Σ_i max_c F_{i,c}(p)          Σ_k s_k(p) = 1
```

F_{i,c}(p) 是镜 i 用候选 c 时在 p 点的热流。各扇区用贪心法在自己的份额 s_k L 下独立求解，可以并行。并集满足 Σ_k flux_k(p) ≤ Σ_k s_k(p) L(p) = L(p)，在所有响应点上可行；随后与其他方法一样做细网格复核、修复和联合姿态复核。份额按“该扇区最多能送到这一点的热流”分配，只有一个扇区能照到的点，份额全部归它。测试 `test_subfield_shares_keep_the_union_within_the_limit` 逐点核对并集不超限。

### 0.6.6 压力工况的光线追迹复核（`validation.py`、界面「光学校验 → 压力工况复核」）

四个工况，各用正式内层设置求出一个方案：

| 工况 | 构造 | 检验什么 |
| --- | --- | --- |
| 低太阳高度 | 冬至上午太阳高度约 10° | 余弦、镜间阴影遮挡与像散最强 |
| 云影边缘 | 夏至正午，直线云影边缘过塔基、沿太阳方位，阴影侧透过率 0.2，过渡带 40 m | 逐镜 DNI 从 20% 到 100% |
| 高负荷混合瞄准 | 夏至正午，λ_APS = 0 | 多种瞄准高度与偏移的光斑叠加 |
| 逼近热流限制 | 同上，全部限值乘 κ，使中心瞄准超限 30% | 方案压到裕度边缘时，“未超限”是否被光线追迹确认 |

同一方案（瞄准点、工作镜、逐镜 DNI）在同一网格上分别用解析模型与 MCRT 计算，分开报告：

- **物理误差**（解析 − 追迹）：吸热器功率、峰值、峰值/限值、热点位置（两图峰值格在圆柱面上的距离）、热流图 NRMSE，附 MCRT 标准误、网格、种子与每镜光线数。
- **求解差距**：(UB − J)/UB，在解析模型内、候选集上计算。
- 判据 `mcrt_within_limit`：追迹平均图在峰值/限值最大格上的值加 2 倍标准误 ≤ 1。

噪声图的最大值偏高（最大值统计量的偏差），光线少时追迹峰值系统地高于解析峰值；解析图取格心值、追迹图是格内平均，这又使追迹峰值偏低。报告的峰值差包含这两部分，要用足够的光线（记录用每镜 2000 条 × 4 个种子）才能把它与模型误差分开。每个方案同时导出 SolTrace 算例：SolTrace 只有一个 DNI，逐镜 DNI 写成反射率系数 dni_i / max dni（按 0.01 分组共享光学属性），驱动脚本把 DNI 设为最大值（`soltrace.export_plan`，测试用模拟的 PySolTrace 核对每面镜的反射率）。

### 0.6.7 求解器对比的规则（`benchmark.py`、`scripts/solver_benchmark.py`）

固定场地、镜数、DNI 空间图、权重和每个方法的时间预算：

- **内层**：同一组工况（按 h_s × DNI 取最大的若干个），同一候选集、网格、裕度。方法：现行贪心、固定响应 0/1 规划（HiGHS，时限 = 预算）、子场分解、贪心 + 松弛取整与对偶上界。只有复核 `ok` 的方案计入。0.7 起仅从同工况的联合姿态上界中取最小值作公共基准。固定响应对偶上界只用于诊断该近似模型，差距都相对它计算；另报“离本工况最好方案的损失”。子场分解另报理想并行时间（最慢扇区）。
- **外层**：现行差分进化（参数化生成器，种群搜索到 80% 预算时停止，再做选择与镜位微调）对比多起点自由镜位优化。后者从初始镜场和若干随机生成器布局出发，每面镜沿单镜年能量的梯度（`certify.potential_map`）移动，加上近邻斥力与随机扰动；中心瞄准初筛得分提高才接受；每一步之后都满足场界与最小镜距；收敛后加扰动继续，直到用完预算（迭代局部搜索）。两者的输出都用正式 V(L) 在设计工况集上评分。天气生成模式还可在同一年重新抽取的代表工况上评分。导入表模式可用 scenarios.validation_file 指定复核表，重复的工况会单独计数；全部重复时复核成绩留空，多个种子给出运行间波动。

## 0.5 空间 DNI 工况与逐工况 APS 年度价值

本节对应 [需求清单](APS-LAYOUT-REQUIREMENTS.md)。代码：[`dni_maps.py`](../src/cspaps/dni_maps.py)、[`scenarios.py`](../src/cspaps/scenarios.py)、[`layout_value.py`](../src/cspaps/layout_value.py)、[`layout_opt.formal_ranking`](../src/cspaps/layout_opt.py)。

### 0.5.1 场地 DNI 地图

场地 Ω 上的一张地图是规则栅格节点 (x_k, y_l) 上的值 g_kl，坐标系为 x 东、y 北、原点在塔底（m）。任意点的值取双线性插值，栅格外取最近边缘值：

```
D(x, y) = Σ_{k,l ∈ 包含 (x,y) 的栅格} w_kl(x, y) g_kl,   w_kl ≥ 0,  Σ w_kl = 1
```

地图只依赖场地坐标，与布局无关。第 i 面镜读 D(x_i, y_i)：两个布局在同一位置读到同一值，镜子挪到别处就在同一张图上读新值。

**单位与归一化。** 倍数地图（`factor`）乘工况 DNI；`site_mean` 归一化使场地内节点平均值为 1：

```
D_s(x, y) = G_s · f_{r(s)}(x, y),     (1/|Ω_h|) Σ_{节点 ∈ Ω} f_r = 1
```

G_s 是气象站 DNI。含义：气象站读数视为场地平均 DNI，地图只在空间上重新分配，不改变场地的辐照总量。绝对地图（`w_m2`）只能配合工况表使用（每个工况指定自己的地图）。

**模型（明确的建模假设，随地图记录在 `dni_maps.json`）：**

| 模型 | 地图 | 用途 |
| --- | --- | --- |
| uniform | f ≡ 1 | 兼容工况，与旧的标量 DNI 路径逐位一致 |
| half_swap | f_± = 1 ± c·tanh(2u/w)，u 为沿罗盘方向 `map_axis_deg` 到塔的距离 | 左右（或南北）半场亮暗及其互换，验收用的两张不同地图 |
| gradient | f_± = 1 ± c·u / max\|u\| | 沿海气溶胶、地形等线性梯度及其镜像 |
| clouds | Π_k [1 − (1 − τ_k) S(d_k)]，S 为半径 r_k、过渡宽 0.3 r_k 的 smoothstep | 碎积云日的云影 |
| file | 导入 CSV（map_id,x,y,value）；规则网格直接使用，散点先 Delaunay 线性插值（凸包外最近邻）栅格化 | 实测或卫星/全天空相机反演 |

**格内最大值。** 双线性插值在矩形上是所接触栅格节点值的凸组合，所以

```
max_{(x,y) ∈ [c_x ± h] × [c_y ± h]} D(x, y) ≤ max{g_kl : 节点 (k,l) 属于与该正方形相交的栅格}
```

`DNIMap.box_max` 按此取值，布局上界用它（见 0.5.6）。测试在随机正方形内的随机点上验证（`test_box_max_bounds_bilinear_map`）。

### 0.5.2 由气象年生成工况集

逐时记录 t（太阳高度角 ≥ `annual.min_sun_elevation_deg`，DNI > 0）有太阳方向 s_t、站点 DNI G_t、时长 w_t。

1. **地图分配（regime）。** `by_day`：一年中的第 k 天全部小时用第 k mod M 张地图；`single`：全部用第一张。分配只决定 DNI 在场地上的分布，不改变量。
2. **按地图分组聚类。** 地图 r 的 DNI 能量 E_r = Σ_{t∈r} G_t w_t；代表工况数 K_r 取 `n_scenarios` 按 E_r 的最大余数分配（每组至少 1 个）。组内用现有的 DNI 能量加权 k-means（`sun.sun_bins`）。工况 s 的方向为成员能量加权平均方向。DNI 与小时数自 0.6 起默认取时间平均与实际小时（`annual.representative_dni: time_mean`，见 0.6.1）：

```
time_mean（默认）:      G_s = Σ G_t w_t / Σ w_t,          h_s = Σ w_t                 ⇒   G_s h_s = Σ_{t∈s} G_t w_t
energy_weighted（0.5）: G_s = Σ G_t² w_t / Σ G_t w_t,     h_s = Σ G_t w_t / G_s
```

3. **守恒。** 对归一化的倍数地图，场地平均 DNI 的年能量严格不变：

```
Σ_s h_s · mean_Ω(D_s) = Σ_s h_s G_s · mean_Ω(f_{r(s)}) = Σ_s h_s G_s = Σ_t w_t G_t
```

   每张地图的能量 E_r 同样保留，所以更密的工况集（同一分配规则、更多 K_r）只改变太阳方向的分辨率，可以直接比较。测试：`test_scenarios_preserve_site_dni_energy_and_round_trip`。

4. **可复用与可追溯。** 工况表四舍五入到保存精度（6 位小数），地图以 17 位有效数字保存；`ScenarioSet.fingerprint()` 是工况表与所用地图的哈希。保存再读入的工况集指纹相同、逐点 DNI 完全相同。比较布局时要求指纹与内层设置摘要都相同（`compare_values` 不同则报错）。

### 0.5.3 内层：固定布局、固定工况的问题一

对布局 L 与工况 s，第 i 面镜的 DNI 为 D_s(x_i, y_i)。内层就是问题一的加权形式：

```
a_s(L) = argmax_{a ∈ A}  J_s(a) = P_s(a) − λ_APS · U_s(a)
P_s(a) = 方案 a 的联合姿态下（阴影、遮挡按各镜自己的法向重算）的吸收功率
U_s(a) = A_H · σ_H(q_a) = A_H · sqrt( Σ_{j∈H} A_j (q_j − q̄_H)² / A_H )
约束：  Q_j(a) ≤ (1 − m) Q_j^max  （细网格完整光斑复核），  P_H ≥ P_min
```

A 包括每面镜的候选瞄准点和散焦。q 是吸收热流（入射 × 吸收率），在**与布局无关**的固定网格上计算：网格尺寸由允许的最近镜位（禁排半径处）可能产生的最小光斑 σ_min 决定，单元 ≤ σ_min/1.5（`eval_grid_shape`），所有布局用同一网格，U 的定义因此对所有布局相同。区域积分按截获功率的数值积分归一化（与问题一相同的 `Snapshot.thermal_objective`）。

**存在性。** 候选集有限；允许散焦且最低负荷为 0 时，全部散焦满足所有通量约束（P = U = 0），所以可行集非空，最优解存在。设置最低负荷时，若无遮挡能量上界 < P_min，则已证不可行（`proven_infeasible`）。

**求解与证书**（`layout_value.solve_instant`，与问题一工作流共用求解器）：贪心构造 + 均匀度坐标搜索 → 可选的拉格朗日对偶 / Frank–Wolfe 松弛取整（固定迭代数，保证可复现）→ 联合姿态邻域搜索（每个候选方案按实际姿态重算阴影遮挡、热流、通量复核）。上界取无遮挡能量上界与热流离散度支撑平面上界中较小者（0.4 节），差距 g_s = (UB_s − J_s)/UB_s。候选组合数 ≤ `aps.coupled_exact_limit` 时联合姿态穷举，即证候选集最优。

**确定性。** 求解不依赖墙钟时间（对偶迭代用次数而不是时限），随机取整与邻域搜索的种子固定，并行时每个工况独立求解，所以同样的布局、工况与设置得到逐位相同的方案。验收测试（`test_independent_task1_reproduces_scores_and_ranking`）把工况集存盘，逐个工况独立调用问题一（`cspaps scenario-aps`），P_s、U_s、状态与布局工作区逐位相同，年度分数与排序一致。

### 0.5.4 外层：同一组方案上的年度价值

```
V(L; λ_L) = Σ_s h_s [P_s − λ_L U_s] = E(L) − λ_L Π(L)          （MWh_th）
E(L) = Σ_s h_s P_s,      Π(L) = Σ_s h_s U_s,      (P_s, U_s) = (P_s, U_s)(a_s(L))
```

性质：

1. **两项权重独立。** λ_APS 决定运行时怎样瞄准（选出 a_s），λ_L 评价这组方案实现的功率与均匀性。外层从原始 P_s、U_s 重新计分，每个工况的惩罚只扣一次（不会出现 J_s − λ_L U_s 这样重复扣分）。
2. **λ_L = λ_APS 时** V = Σ_s h_s J_s，即各工况内层得分的加权和。
3. **方案固定时 V 对 λ_L 是仿射函数**：∂V/∂λ_L = −Π(L)。改变 λ_L 不需要重新求解，P_s、U_s 不变，分数按公式精确变化（`test_outer_weight_rescoring_is_exact`）。两个布局的直线 V_A(λ)、V_B(λ) 在 λ* = (E_A − E_B)/(Π_A − Π_B) 处相交，λ_L 越过 λ* 时排名互换（界面“外层权重重新计分”画出这些直线）。
4. **优势分解。** 在同一工况集上

```
V_A − V_B = (E_A − E_B)  +  [−λ_L (Π_A − Π_B)]
             更多吸热           更均匀受热
```

   先在每个工况考核热流不均匀，再按小时累加：不同时间的热点不会在年平均热流图上相互抵消（Π 是各工况 A_H σ_H 的加权和，不是年平均热流图的 σ）。

5. **周向指标仅作对照。** 每个工况也记录周向部分 A_H σ_circ（扇区平均热流的离散度，布局决定、APS 无法消除的部分），排名不用它。

**状态与计分**（`layout_value.STATUS_RULES`）：

| 状态 | 含义 | 计入 V |
| --- | --- | --- |
| feasible | 通过细网格复核且有工作镜的方案 | h_s (P_s − λ_L U_s) |
| feasible_shutdown | 最优可行方案是全部散焦（例如均匀性惩罚大于功率） | 0（P = U = 0，是可执行方案） |
| no_sun | 太阳低于地平线或无 DNI | 0 |
| no_feasible_found | 预算内没有通过复核的方案，也未证明不可行 | 0（吸热器保持停机；V 是该布局模型价值的下界） |
| proven_infeasible | 已证明约束下不存在运行方案 | 0 |
| not_solved | 未计算（取消） | 年度价值不完整，不参与排名 |

导出的 `scenario_values.csv` 每行含工况 ID、地图 ID、代表小时、太阳位置、DNI、状态、`counts_in_value`、P_s、U_s、贡献、内层上界与差距、峰值、散焦数及逐镜瞄准文件 `aims/<工况>.csv`。仅凭该表即可复算：V = Σ_{counts_in_value} hours × (p_abs_mw − λ_L × u_mw)（`cspaps rescore`、界面“仅凭导出文件复算”）。

### 0.5.5 布局搜索与正式排名

外层搜索算法可独立选择。实现采用：

1. **初筛**（标注为快速初筛）：参数化生成器 + 差分进化 + 交换选择，按中心瞄准的全年理论热量减周向不均匀惩罚评价，工况带同样的地图（每面候选镜按位置读 DNI）。
2. **正式排名**：初筛前 `refine_top` 个不同布局，以及初始镜场（取最靠近塔的 N 面，等镜数对照），在同一工况集、同一内层设置上逐个工况求解问题一，按 V(L) 排名。
3. **按 V 接受的换位**：对排名领先的搜索布局，移出 APS 年吸收最少的镜子、换入按“加入当前布局后”定价最高的空闲候选镜位，只有在同一工况集上 V 提高才接受（单调）。
4. **更密工况复核**：胜出布局与初始布局在 `dense_check_scenarios` 个工况（同一地图分配规则）上重算，报告代表工况的相对误差与排序是否一致。

### 0.5.6 最优性结论的范围

- **内层差距**：每个工况 g_s；年度加权 G_in = 1 − Σ h_s J_s / Σ h_s UB_s（λ_L = λ_APS 时就是 V 相对“各工况都取最优运行”的差距上限）。
- **外层上界**：对任意 N 面镜布局、任意瞄准点，

```
V(L) ≤ E(L) ≤ Σ_i e⁺(x_i) ≤ ∫_0^∞ min(N, cap{x : e⁺(x) ≥ t}) dt
e⁺(cell) = Σ_s h_s · G_s · max_{cell} f_s · g_s⁺(cell)
```

  g_s⁺ 是单位 DNI 的单镜无干扰吸收上界（余弦按方向最大偏转、衰减按最短斜距、截断按最小光斑、吸收率按可达管屏最大值，0.2 节）；max_cell f_s 由 0.5.1 的格内最大值给出，所以上界对格内任意位置成立。第一步用 U ≥ 0、λ_L ≥ 0。上界只对所用工况集成立（结果里写明工况集指纹）。差距 1 − V/上界 是保守值，包含遮挡、通量限制与均匀性惩罚造成的全部损失。
- **小镜场穷举**（`test_small_field_inner_and_outer_layers_against_brute_force`）：3 面镜 × 4 个动作，通量约束起作用（64 组姿态中有拒绝），独立的暴力枚举与内层求解的 J 相同并被证为最优；外层枚举 4 个候选镜位中选 3 个的全部 4 种布局，正式排名的最高 V 等于穷举最大值，且地图下的布局上界 ≥ 最大 E ≥ 最大 V。
- **代表工况误差**：0.5.5 第 4 步。中心瞄准的逐时复核只验证中心瞄准指标，不用于 V(L)。
- **地图的可推广性（云影模型）**：云影是瞬时现象。每张云图按日轮换在全年重复使用，有限张云图上的 V 是带噪声的估计；在这组固定的云影位置上取最大，会选出“躲云”的布局（赢家诅咒）。`layout_opt.cross_check_maps` 在云影模型下用独立的随机云图（种子 + 1000）重新求解胜出布局与初始布局，报告领先幅度是否保持。哈密算例：正式云图上领先 +1,244 MWhₜₕ，独立云图上 −589（详见 README）。持久性的空间特征（气溶胶梯度、地形遮蔽、长期观测的平均地图）才适合决定镜位。

## 0.4 联合姿态与年度加权目标

对固定镜场，令一个方案 a 包含全部镜子的候选点或散焦动作。每次执行评价都使用 a 的整组法向重算遮挡，散焦镜在模型中保留中心姿态并停止向接收器送能。在等面积网格上，吸收热流按截获功率积分归一化。考核区域 H 上的加权目标为 J = P_abs − λ A_H σ_H。CV 上限模式要求正的区域负荷，加权模式在允许停机且最低负荷为零时可取零功率。通量约束使用预测与当前 DNI 的逐镜较大值，并保留设置的安全裕度。

- 候选组合数不超过 `aps.coupled_exact_limit` 时，联合姿态枚举给出数值模型的离散最优解或不可行证明。连续接收器表面的通量峰值用自适应网格及热点加密检查。
- 大问题使用固定响应求解器生成初始方案，再搜索联合姿态。去掉遮挡及非负的均匀度惩罚，逐镜独立选择最大吸收功率，即可得到保守上界。加权模式还以中心化吸收热流的单位方向构造离散度范数的支撑平面。各镜遮挡因子放松为 [0,1]，网格能量归一化因子取各非零光束的积分比值上界。两个上界取较小者。连续瞄准的单独上界由接收器包围球对每面镜张开的方向锥与能量守恒给出。
- 候选集存在性分为已找到可行解、已证不可行和未判定。固定响应矩阵的对偶间隙用于改进方案，界面显示联合姿态证书。

布局搜索的目标为 J_L = Σ w_t [P_t − λ_L S_t]。`uniformity_metric` 可取 `circumferential` 或 `surface`，后者使用同一时刻实际受热面上的二维离散度。生成器筛选先使用管屏分布，复核和连续镜位微调按选择的目标评分。镜数、中心距、场界、禁排区贯穿候选生成和坐标微调。中心瞄准模式评估理论能量，APS 模式使用通过运行可行性检查的时段。标准演示按逐时中心瞄准结果复排。

对于同一批代表工况，几何与堆积给出年能量上界。对于逐时理论目标，对各太阳方位分组保留完整 DNI 时间权重，利用半角余弦函数的凹性、镜位格及接收器的方向锥求单镜能量包络，再应用堆积容量上界。代表工况与逐时目标分别输出上下界。有限评估集有最优解，任意连续镜位上的取到性还要求非空紧可行域和上半连续目标。离散遮挡命中计数会随镜位跳变。

## 0.3 固定响应模型的推导与历史基准

下面的线性响应与对偶推导用于初始方案求解。端到端证明采用上文的联合姿态模型。

### 0.1 问题一：固定镜场的瞄准点优化

**给定**：镜场坐标、镜面数量与尺寸、集热器三维坐标、逐镜 DNI 分布 D_i。**控制变量**：每面定日镜的瞄准点（候选点 k，或散焦）。x_ik ∈ {0, 1}，Σ_k x_ik ≤ 1。

```
P(x)   = Σ c_ik x_ik                        吸收功率（c_ik：候选点 k 的吸收功率）
q(x)   = 考核区 H 各网格的吸收热流（对 x 线性）
S(x)   = A_H · σ_H(q) = a √|H| ‖q − mean(q)‖   （凸函数）
P_H(x) = a Σ_H q                             考核区吸收功率（线性）
通量：  (A x)_m ≤ 1   每个约束点 m（行按允许通量归一化，含安全裕度）

power     max P(x)
weighted  max P(x) − λ S(x)       = P − λ · CV_2D · P_H     λ：均匀性的重要性超参数
cv_limit  max P(x)  s.t.  S(x) ≤ ε P_H(x),  P_H(x) ≥ P_min
```

**存在性**：候选集合有限，"全部散焦"满足全部通量约束，可行集非空，所以 power 和 weighted 模式的最优解一定存在；cv_limit 模式在可行时存在（设置最低负荷后可能不可行）。把瞄准点看成吸热器表面上的连续变量时，可行集是紧集，热流对瞄准点连续，由 Weierstrass 定理最优解同样存在；候选点加密时离散最优值收敛到连续最优值。最优解一般不唯一。

**上界（证书）**：对乘子 ν、μ、ρ ≥ 0，

```
L(x) = P(x) − (λ + μ) S(x) + μ ε P_H(x) + ρ (P_H(x) − P_min) − ν·(A x − 1)
```

对 x 是凹函数，并且在每个可行方案处不小于目标值（弱对偶）。把 x 放松到 [0, 1]，记 Δ 为各镜单纯形的乘积，凹性给出

```
OPT ≤ max_Δ L ≤ L(x_t) + max_{y∈Δ} ∇L(x_t)·(y − x_t)
```

右端按镜可分离（每面镜取系数最大且为正的候选点，否则散焦），只需稀疏矩阵向量乘。x 走 Frank–Wolfe 步（凹一维精确线搜索），乘子走投影次梯度步；**每一步都是有效上界**，取最小。于是

```
本方案目标值 ≤ 全局最优（候选模型） ≤ 上界，   差距 = 1 − 本方案 / 上界
```

cv_limit 模式下若上界为负，即证明在通量和最低负荷约束下不存在满足 CV 目标的方案。上界对本候选集和约束点（求解网格 + 复核热点）成立；只用到更少约束，所以对细网格可行方案同样成立。

**松弛引导取整**：上界迭代同时给出松弛解。按松弛解取整（逐镜取最大分量，以及若干次随机取整）→ 贪心修复通量 → 目标函数下的坐标搜索，保留最好的方案，再做细网格复核（热点加入约束、修复）。只在目标值严格提高且复核通过时替换原方案。

**阿克塞演示**（473 面镜，2024-03-19 15:00，DNI 1136.7 W/m²）：

| 模式 | 吸收功率 (MW) | 二维 CV | 差距 |
| --- | --- | --- | --- |
| 功率最大 | 24.188 | 1.101 | 0.00%（候选集上已证全局最优） |
| λ = 0.3 | 23.25 | 0.256 | 0.11% |
| λ = 1.0 | 21.15 | 0.089 | 1.2% |

测试中用穷举（(K+1)^N 个方案）和 SCIP 精确解验证：上界始终不低于真实最优值。

**证书的范围与连续瞄准点**。证书针对离散候选瞄准点（默认每面镜 3 个方位 × 7 个高度 = 21 个）。真实瞄准点是吸热器表面上的连续量（或受控制器指令分辨率限制）。对连续瞄准点给出严格上界需要目标函数对瞄准位置的 Lipschitz 常数，按光斑梯度估算，这一余量比单面镜的功率还大，没有实用价值。因此软件给出嵌套加密的收敛分析（`cspaps aps-refine`、界面「最优性证书 → 候选点加密收敛性」）：每一级候选网格包含上一级（方位、高度步长减半），从上一级方案出发求解，本方案只增不减，并给出该级上界。阿克塞（λ = 0.3，2024-03-19 15:00）：

| 候选网格（方位步长 / 高度步长） | 本方案 (MW) | 上界 (MW) | 差距 |
| --- | --- | --- | --- |
| 3 × 7（6° / 1.2 m） | 21.462 | 21.487 | 0.11% |
| 5 × 13（3° / 0.6 m） | 21.562 | 21.587 | 0.12% |
| 9 × 25（1.5° / 0.3 m） | 21.595 | 21.611 | 0.07% |

上界逐级增量 +0.100、+0.024 MW，迅速收敛；默认 21 点网格比 1.5° / 0.3 m 网格的方案低约 0.6%。当候选网格取到瞄准控制的指令分辨率时，候选集就是全部可执行方案，证书即完整。

### 0.2 问题二：给定场地的镜场布置

**给定**：场地 Ω（多边形边界、塔周禁排区）、镜数 N、镜面尺寸、集热器三维坐标、经纬度（决定全年太阳位置）与气象。

```
max_X  E(X) = Σ_t w_t Σ_i P_i(X, t)      s.t.  x_i ∈ Ω,  ‖x_i − x_j‖ ≥ d   (i ≠ j)
```

**为什么布局必须考虑均匀性**（`layout_uniformity.py`）。圆柱外置式吸热器的每一侧只被朝向它的定日镜照射：方位 φ_i 的定日镜（从塔轴看）在像平面上看到宽 2R 的吸热器轮廓，表面方位 φ 对应横向坐标 u = R·sin(φ − φ_i)（|φ − φ_i| < 90°）。横向高斯光斑（σ_i）分到方位列 [φ_a, φ_b] 的功率比例为

```
s_ij = [Φ(R sin(φ_b − φ_i)/σ_i) − Φ(R sin(φ_a − φ_i)/σ_i)] / [Φ(R/σ_i) − Φ(−R/σ_i)]
```

与完整 HFLCAL 通量图的列积分相比，最大列误差 0.12%（相关系数 0.999995）。APS 只能沿高度、在几度范围内移动瞄准点，能抹平每列内部的差异，但不能把北侧的热流搬到南侧。等面积列的方差分解

```
σ²_2D = σ²_circ（列平均之间，由布局决定） + 列内方差的平均（APS 可调）
```

说明周向部分是问题一均匀度惩罚中任何瞄准策略都去不掉的部分。布局阶段按**管屏（扇区）**而不是按网格列计算 σ_circ：每列取所在管屏的平均值，再对等面积列求标准差，即面积加权的管屏间标准差（`layout_opt.uniformity_sectors`，默认按管屏；管屏少于 6 块时用 12 个 30° 扇区）。管屏内部的起伏（单个近处镜子的窄光斑只照亮一两列）由瞄准偏移和大量光斑的重叠调平；若按列计算，惩罚会偏爱光斑更宽的远处镜子，在小镜场里选出离群的远镜。按管屏计算也对应工程上的管屏间吸热平衡（每块管屏是一条流程）。只按全年能量布置时，高纬度场址的镜子会集中在塔北侧：阿克塞 473 面镜的能量最优布局有 94.5% 的镜子在塔北，能量质心离塔 173 m，周向 CV 1.03；吸热器南侧 30° 扇区只分到 0.4% 的年热量，北侧 23%。在这个布局上即使用问题一的 λ = 1，二维 CV 也只能降到 0.71，吸收功率还掉了一半。

**带均匀度的目标**（与问题一的加权目标同构，λ_L = `layout_opt.uniformity_weight`）：

```
max_X  J(X) = Σ_t w_t [P_t(X) − λ_L · A_H · σ_circ,t(X)] = Σ_t w_t P_t (1 − λ_L CV_circ,t)
```

σ_circ,t 为工况 t 下考核区各管屏平均吸收热流的标准差。固定生成参数时，从候选镜位中选 N 个是 max J(x)，Σx = N，x ∈ {0,1}；J 对松弛变量是凹函数，用交换局部搜索求解，并用 Frank–Wolfe 上界（线性子问题为取前 N 大）证明选择的差距。λ_L = 0 时退化为“年收益最高的 N 个”。

**候选镜位的定价必须与选择一致**（`layout_opt.select_consistent`）。生成器先铺满场地（阿克塞约 2,300 个候选位置，最终只建 473 面）。若在全部候选组成的密集镜场里计算每个位置的功率，每个候选都要承受从不建造的候选造成的阴影遮挡；这一人为损失随候选密度变化且不随距离单调——阿克塞北侧 230–290 m 的候选密集，平均只有 74–76 MWh，而 290–330 m 处生成器换区、邻居变少，反而有 78–80 MWh。于是选择会跳过近处位置，选出离主镜场 85 m 的 3 面孤立远镜（审计发现）。现在的做法：

1. 只让已选镜子遮挡，重新计算所有候选的功率（已选镜子得到真实功率，未选候选得到“加入当前布局后”的功率）；
2. 从当前选择出发重新选择；只有当真实目标值提高时才接受这一步，否则把允许的换位数减半（阻尼），因此不会来回振荡；
3. 复核阶段再做完整换位邻域搜索：对每面已选镜子，在排名靠前的 300 个候选中精确找最优替换。筛选换位对时除了单步增益，还用线性化目标（同一扇区内换位时惩罚变化相互抵消），否则同扇区的有利换位会被漏掉。

结果对每个选择都校验“没有任何单次换位能提高目标值”（测试中逐对穷举），并报告脱离主镜场的镜子数（与主镜场距离超过中位镜距 3 倍的连通分量）。阿克塞 λ_L = 0.3：孤立远镜从 3 面降为 0，全年理论吸收由 33,700 变为 33,709 MWhₜₕ，受限 APS 可行能量由 32,140 提高到 32,167 MWhₜₕ。

两种布局在问题一中的表现（2024-03-19 15:00，DNI 1136.7 W/m²，细网格复核）：

| 问题一的权重 λ | λ_L = 0 布局：吸收功率 / 二维 CV / 周向 CV | λ_L = 0.3 布局：吸收功率 / 二维 CV / 周向 CV |

| 0 | 26.32 MW / 1.42 / 0.98 | 24.15 MW / 0.78 / 0.13 |

**存在性**：可行集 {X : x_i ∈ Ω, ‖x_i − x_j‖ ≥ d} 有界且闭，即紧集；年能量与周向惩罚都对镜位连续（阴影遮挡是面积分数，随镜位连续变化），所以只要可行集非空，最优布置一定存在。对称场地上最优布置一般不唯一。

**上界**：e0(x) 为位置 x 处单镜在**无邻镜**时的年吸收热量（余弦、反射、衰减、截断、吸收率）。邻镜阴影遮挡和通量约束只会减少能量，所以 E(X) ≤ Σ e0(x_i)。再用层饼积分：

```
Σ_i e0(x_i) = ∫_0^∞ #{i : e0(x_i) ≥ t} dt ≤ ∫_0^∞ min(N, cap(L_t)) dt,     L_t = {x ∈ Ω : e0(x) ≥ t}
cap(S) ≤ area(S ⊕ B(d/√3)) / (√3 d² / 2)
```

后一式来自 Fejes Tóth：镜距 ≥ d 的点集，各点 Voronoi 胞与半径 d/√3 圆盘的交互不重叠、面积不小于 √3 d²/2。

**栅格上的严格做法**（`certify.cell_energy_upper_bound`）。场地用正方形栅格覆盖（所有与场地相交的格子），对每个格子求一个对格内**任意位置**都成立的 e0 上界，而不是只在格子中心取样：设格子半对角线 ρ，镜→瞄准点向量 v(x) 与格子中心的 v(c) 相差不超过 ε = ρ(1 + R/r_min) + √(2R² + (H/2)²)（后一项允许瞄准点在吸热器可见面上任意移动，所以上界对任何瞄准策略都成立），方向最多转过 δ = asin(ε/|v(c)|)。逐工况：

| 因子 | 格内上界 |
| --- | --- |
| 余弦 cos(θ/2) | cos(max(0, θ_c − δ)/2) |
| 大气衰减（随斜距单调递减） | 斜距取 \|v(c)\| − ε 时的值 |
| 截断 | 吸热器轮廓包含在 \|u\| ≤ R、\|v\| ≤ (H/2)cosβ + R sinβ 的矩形内；居中矩形的高斯质量最大，σ 取格内最小值 D_min·σ_0 |
| 吸收率 | 光斑可能落到的管屏中的最大吸收率，加 5σ 尾部按全局最大吸收率计 |

层饼积分中的区域 L_t 取上界 ≥ t 的格子之并，圆盘膨胀半径取 d/√3 + √2·格宽（格内任意位置 + 格子部分覆盖）。这样每一步都是不等式，不依赖采样密度。

**审计修正**（2026-11-21）：此前用格子中心取样再取 3×3 邻域最大值，峰值落在格点之间时会略微低估；单镜只按正对管屏的吸收率计算，而光斑会落到相邻管屏；快速能量计算（不算通量图时）用全部管屏的平均吸收率。三处都已修正：上界改为上面的逐格严格界；吸收率按光斑在各管屏上的分布加权（`receiver.effective_absorptivity`，与细网格通量图一致）；差距不再截断为 0，若本方案超过上界则报告 `bound_violation`。对 2 万个随机位置、正对/相邻管屏吸收率相差 3 倍的算例做了校验，没有任何位置超过所在格子的上界。

- 若 N 大于整个场地的容量上界，即证明**不存在**满足镜距的布置；
- 否则给出 “本方案 ≤ 全局最优 ≤ 上界” 与差距。上界忽略阴影遮挡并允许最密堆积，偏乐观；真实最优值介于两者之间。
- λ_L > 0 时 J ≤ E（管屏间惩罚 ≥ 0），所以能量上界同样是 J 的上界，结果中单独报告为 `gap_objective_conservative`（阿克塞约 21%）。没有比这更紧的通用上界：任何布局都可能在管屏间分配上恰好均衡，惩罚的下界只能取 0；此时布局为了均匀受热主动让出部分能量，能量差距相应变大（阿克塞 λ_L = 0.3：14.2%），这部分差距是均匀性的代价，不是搜索不足。

**阿克塞演示**（N = 473，840 m × 780 m 场地，禁排半径 50 m，6 个复核工况）：任意布局、任意瞄准策略的年吸收热量上界 39,283 MWhₜₕ。只追求能量（λ_L = 0）时全年理论吸收 36,435 MWhₜₕ，差距 ≤ 7.3%；演示默认 λ_L = 0.3，全年理论吸收 33,709 MWhₜₕ（差距 ≤ 14.2%），受限 APS 可行能量 32,167 MWhₜₕ。


## 1. 功率链

每面镜子 i 送到集热器表面的截获功率：

```
P_i = DNI_i · A · η_cos · ρ·清洁度 · η_阴影 · η_遮挡 · η_衰减 · η_截断
```

吸收功率 = 截获功率 × 吸收率（可按管屏设置吸收率）。各环节按顺序记录在 `simulate.STAGES`，结果中同时给出截获功率和吸收功率。`DNI_i` 可以逐镜不同（云影）；散焦的镜子截断为 0。

| 环节 | 模型 | 代码 |
| --- | --- | --- |
| 太阳位置 | NREL SPA（pvlib） | `sun.solar_position` |
| DNI | Meinel 晴空模型 + 海拔修正 / 常数 / 气象文件（EPW、CSV） | `sun.dni`, `sun.load_weather` |
| 余弦 | 镜面法向 = 太阳方向与镜→瞄准点方向的角平分线 | `optics.heliostat_geometry` |
| 阴影、遮挡 | 镜面采样点的光线–矩形求交，含塔影 | `shading.shading_blocking` |
| 大气衰减 | Vittitoe-Biggs 晴天 / 霾天，或 Beer-Lambert | `optics.attenuation` |
| 光斑与截断 | HFLCAL 圆高斯 + 圆柱面投影 + 一维求积 | `optics.beam_sigma`, `optics.intercept_fraction` |
| 通量分布 | 全部光斑在圆柱面上线性叠加 | `optics.flux_on_receiver` |

## 2. 集热器、管屏与通量限值

圆柱面按 `n_panels` 等分为管屏，1 号管屏从 `panel_start_azimuth_deg` 开始顺时针。每个点的允许通量：

```
允许入射通量(点) = 管屏限值 × 高度系数(z) ÷ [吸收率（若限值按吸收通量给出）] ÷ 管屏偏差系数
```

- 高度系数 `limit_height_profile` 从下到上线性插值；
- 偏差系数 `panel_flux_bias` = 实测通量 / 模型通量，是运行反馈的接口：某块管屏实测比模型高 10%，就填 1.1，该管屏的允许模型通量自动降低；
- 优化器、复核、界面和命令行都统一换算成"允许的模型入射通量"来比较（`receiver.incident_limit_w_m2`）。

## 3. 阴影与遮挡

- 定日镜为矩形，方位–高度角跟踪（宽度方向保持水平），每面镜子取 n×n 个采样点（默认 8×8）。
- **阴影**：采样点向太阳的光线打到邻近镜子或塔身（竖直圆柱，高至集热器顶）。
- **遮挡**：采样点向瞄准点的反射光线打到邻近镜子。损失按并集计算，不重复扣除。
- **邻居筛选**：KD 树找一定半径内的镜对（半径由太阳高度角和反射光仰角决定，缓存在镜场上），每个时刻再只保留光线方向走廊内（横向距离小于对角线）的邻居。
- **筛选复核**（`shading.compare_screening`、`cspaps shading-check`）：与不做任何筛选的全对暴力求交逐镜比较。在低太阳高度角、密集镜位、远端镜、边缘瞄准四种工况下，示例镜场都完全一致（漏判 0），筛选快 40–200 倍。因此没有另外引入 SolTrace 式的投影索引。

## 4. 光斑模型（HFLCAL）

像平面上的光斑为圆高斯，标准差：

```
σ = D · sqrt(σ_sun² + (2σ_slope)² + (2σ_track)² + σ_spec² + σ_ast²)
```

| 符号 | 含义 |
| --- | --- |
| D | 斜距 |
| σ_sun | 太阳形状（高斯取 σ，圆盘取 半角/2） |
| σ_slope, σ_track | 镜面法向误差，反射后角度加倍 |
| σ_spec | 镜面散射，作用在反射光线上，不加倍 |
| σ_ast | 像散项 |

像散项：`σ_ast = sqrt(0.5·(H_t² + W_s²)) / (4D)`，`H_t = d·|D/f − cos ω|`，`W_s = d·|D/f·cos ω − 1|`。

- **投影到圆柱面**：表面点沿主光线投影到像平面，乘入射余弦；背光半圆为 0。
- **截断效率**：对圆柱侧面在像平面上的投影带做一维 Gauss-Legendre 积分，节点集中在光斑中心 ±8σ，与网格粗细无关。同一公式可以只对某个高度带积分，第 8 节的边缘带上界就用它来算带内功率。

## 5. 内层：瞄准点优化（APS）

### 5.1 问题

固定镜场和时刻，为每面镜子 i 选一个候选点 k，或者让它散焦：

```
max   Σ_i D_i · p_ik
s.t.  Σ_i Dc_i · K_ik(m) ≤ (1 − 裕度) · F_lim(m)      对每个约束点 m
```

- `K_ik` 是单位 DNI 下的通量响应（含光斑、遮挡和光学损失）；
- `D_i` 是当前 DNI，`Dc_i` 是约束用 DNI（当前值，或预报时段内的最大值）。
- 候选点为正对方位加周向偏移（默认 −4°、0、+4°），乘以高度层（默认 9 层，覆盖 90% 高度）。每个候选点都重算法向、余弦、斜距、σ 和截断效率。

### 5.2 响应与 DNI 分离（`aps.ResponseSet`）

与 DNI 无关的部分只建一次：几何、遮挡、截断效率，以及稀疏的单位 DNI 响应（保留不低于自身峰值 0.2% 的网格）。每轮更新 DNI 只需要逐行缩放。

阴影与遮挡**按每个候选瞄准点分别计算**（`ResponseSet.sb_k`）：不同瞄准点对应不同的镜面法向和反射光方向。高太阳时差别为零，低太阳时可达 20 个百分点（阿克塞 12 月 21 日 09:30，473 面镜中 80 面差别超过 0.5%），计算耗时 0.04–0.5 s。

求解网格会按最窄光斑自动加密（单格不超过 σ_min/1.5），细节由下面的复核兜底。

### 5.3 求解器

| 方法 | 做法 |
| --- | --- |
| `center` | 全部瞄准正对面的中心高度（基准） |
| `kfactor` | z = z_c ± (H/2 − kσ_i)，按扇区上下交替；二分求满足限值的最大 k |
| `greedy`（默认） | 冷启动：按光斑从大到小依次放置，选可行且功率最高的候选点，平局时选局部通量最低的点；之后做坐标下降。热启动：从上一轮已执行方案出发，先让造成超限的镜子移开或散焦，再重算优先集合（DNI 变化大、处在热点附近、处于散焦或刚恢复可用的镜子） |
| `milp` | 0/1 整数规划（HiGHS），用于小规模；其 LP 松弛给出功率上界 |

单时刻计算（`cspaps aps`、界面「瞄准优化」）默认在上述求解之后运行第 0.1 节的证书：对偶上界 + 松弛引导取整，结果附 `certificate`（上界、差距、状态）和 `existence`（存在性结论）。全年和布局循环内不运行证书，以保持速度。`cspaps pareto` 扫描权重 λ，每个点都是完整流程（坐标搜索、松弛取整、细网格复核、上界）。

附加约束：

- 可用状态：不可用的镜子强制散焦；
- 可达性：候选点要求的法向变化须在"转速 ×（延迟 + 周期）"以内；
- 移动惩罚：瞄准点移动越远，扣除的功率越多，使方案平滑变化。

### 5.4 可行性复核与约束生成（`verify.py`）

求解用的是粗网格和截尾光斑，粗网格会漏掉窄光斑的峰值：导师给的算例中，12×8 网格报 4.18 kW/m²，真实峰值是 19.5。所以每个解都要复核：

1. 网格间距 ≤ σ_min/3，σ_min 是当前方案里最窄的光斑；
2. 用约束 DNI 完整叠加全部光斑，不截尾；
3. 在最热的若干个局部极大点周围，用 1/4 间距的 9×9 子网格精化峰值，误差小于 0.4%；
4. 每个点与该点所在管屏的允许通量比较。

超过"允许值（扣除裕度）"的局部极大点加入约束集，重新求解，最多 `verify_max_rounds` 轮。最终状态：

| 状态 | 含义 |
| --- | --- |
| `ok` | 不超过扣除裕度后的允许值 |
| `margin_reduced` | 不超过限值，但用掉了部分裕度 |
| `infeasible` | 超过限值，同时给出热点位置、所在管屏、超限量和主要贡献镜 |

命令行在 `infeasible` 时返回退出码 2。

**复核的收敛与标签**。精确法（MILP）每轮都从头求解，新的约束点可能把通量推到别处，割平面轮数事先无法保证（审计中一个小算例需要 5 轮，而默认上限是 4 轮）。现在 MILP 最多 12 轮；若仍不通过，就从当前方案出发修复——只移动或散焦供给超限点的镜子，直到通过复核。只有当最终方案就是精确法自己的最优解（没有经过修复）**并且**通过细网格复核时，才标记 `global_optimality_proven`；复核失败的方案标为 `infeasible_after_verification`，也不会附带最优性证书。

**单时刻结果的最终复核**（`workflows.task_aim`）：不再沿用求解器内部的复核，而是对最终瞄准点重新计算阴影遮挡、用完整光斑在细网格上复核（有预报时用约束 DNI），状态由这一复核决定；求解器的复核作为 `solver_flux_check` 一并保存。

## 6. 均匀受热（第五、六节）

### 6.1 指标

H 为预热器考核区（若干管屏和高度范围），暗区也计入面积；q 为吸收通量。

- 二维 CV = 面积加权标准差 / 面积加权均值；
- 周向 CV：先按高度求平均，再在各列之间算 CV；
- 高度 CV：先按周向求平均，再在各行之间算 CV。

以示例在夏至 13:40 的贪心解为例：二维 CV 0.717、周向 0.142、高度 0.694，可见上下受热差在周向汇总中被掩盖了。

### 6.2 带均匀度约束的 APS（`uniformity.solve_uniform`）

```
max P_abs   s.t.  通量限值，CV_2D(H) ≤ ε，A_H·q̄_H ≥ P_H,min
```

用拉格朗日局部搜索求解：最大化 `P_abs − μ·A_H·std_H(q)`。单面镜子换点时，Σq 和 Σq² 可以增量更新；对权重 μ 做二分，取满足 ε 的最小 μ。

- 固定权重模式（`mode: weighted`）直接最大化 `P_abs − λ·A_H·σ_H`，坐标搜索跑到没有改进为止（上限 25 轮）；
- 达不到最低负荷时记为 `below_min_load`，按停机处理（全部散焦）；
- 示例（夏至 13:40）：ε = 0.55 时二维 CV 从 0.717 降到 0.548，截获功率只降 0.3%。

### 6.3 ε 扫描与精确基准

`uniformity.sweep` 给出功率–均匀度曲线。启发式结果标为"已知最好可行"或"未达到"。小规模问题可以加 `--exact`，用 SCIP 解混合整数二阶锥规划，状态为"已证最优""除停机外不可行""限时可行"之一。测试中验证了：放宽 ε 时，被证明的最优功率单调不减。

### 6.4 上下边缘功率上界（第六节，`uniformity.edge_band_bound`）

B 为顶、底各 1/8 高度的两条带，面积占比 a = 0.25。要求总截获功率至少为 L，放松峰值和均匀度约束：

```
U(λ) = Σ_i max_k (b_ik + λ p_ik) − λL ≥ P_B，   λ ≥ 0
u = min_λ U(λ) / L
CV_2D ≥ max(0, a − u) / sqrt(a(1 − a))
```

其中 b_ik 是候选点 k 落在 B 内的功率，用精确的高度带截断效率计算。

示例中取 L 为贪心解功率的 99.5%，得到 u ≤ 8.0%，二维 CV 下界 0.39，与评审稿的数值一致。只有当已证下界高于目标时，才把该目标标为"在此候选集模型下不可达"。

## 7. 在线控制引擎（`engine.py`）

每个控制周期调用一次 `APSEngine.step(ControlRequest)`。

**输入**：时刻、逐镜当前 DNI 及其时间戳、带有效时刻的预报快照、镜子可用状态、上一轮执行回执。

**处理流程**：

1. **数据检查**。DNI 缺失、非法或过期（超过 `max_dni_age_s`）时，约束改用晴空 DNI。若预报没有覆盖方案生效时段 [t + 延迟, t + 延迟 + 周期]，也用晴空 DNI。
2. **约束 DNI**。取覆盖时段内各预报快照的逐镜最大值，乘以 (1 + 预报裕度)，且不低于当前值。没有预报时，默认按晴空 DNI（保守）。
3. **响应缓存**。太阳移动不超过 `response_refresh_deg` 时复用；历次复核加入的热点约束点也一并保留。
4. **热启动求解**。从回执中的已执行方案出发，带可达性筛选和求解时限。
5. **最终复核**。用当前太阳几何（重算遮挡）和约束 DNI 在细网格上复核；有热点就加入约束、修复。仍不通过时按配置回退：上一轮方案能通过复核就沿用，否则散焦主要贡献镜。

**状态**：`ready`（可执行）、`fallback`（已回退，附原因）、`infeasible`（不可执行，由控制端进入保守策略）。场站的安全联锁独立于 APS，保持不变。

示例算例（1532 面镜）的耗时：冷启动约 3.4 s，其中构建响应约 1.9 s；复用缓存时约 0.35–0.45 s，其中求解只要 0.06–0.13 s。

**服务方式**：`cspaps engine CASE` 以 JSON 行的形式从标准输入读请求、向标准输出写响应，DNI 可以按镜子 ID 给出。

## 8. 云影回放（`realtime.py`）

**场景**：随机云、云边扫过（`moving_edge`）、云突然移开（`sudden_clear`），以及 DNI 数据延迟（`dni_delay_s`）或丢失（`dni_dropout_s`）。

**时间口径**：采样时刻为 0、步长、2×步长……以及回放终点；第 k 个采样代表区间 [t_k, t_k+1)，终点区间长度为 0。

- 能量 = Σ 功率 × 区间长度；
- 超限时长 = 超限采样所代表区间的长度之和；
- 3 分钟回放（60 s 步长）共 3 个区间，150 s 回放为 60、60、30 s。

**判定方式**：在 t_k 算出的方案从 t_k+1 起生效（一个周期的延迟）。每个生效方案都用实际 DNI 做细网格复核，超限判定以复核结果为准。

**结果**：同时输出各策略的端到端延迟 P50/P95、冷启动次数、超时次数和方案状态统计。

## 9. 全年能量与采样（`sun.py`）

| 方式 | 做法 |
| --- | --- |
| `sun_bins` | 全年白天各时刻的太阳方向做 DNI 能量加权 k-means（竖直分量放大 3 倍，使低太阳高度角分得更细）；20 / 30 / 40 或任意个数 |
| `sun_grid` | 按太阳高度角 × 方位角分箱 |
| `hourly` | 全年逐时；有气象文件时用文件原始步长 |
| `representative_days` | 每月一天 |

- **能量守恒**：每个代表点的 DNI × 权重 = 所含小时的 DNI 能量之和，全年 DNI 总量严格守恒。
- **DNI 分档**（`dni_bands`）：受限 APS 的功率对 DNI 不是线性的。评审稿指出，DNI 300 和 1200 W/m² 的工况合并后，受限 APS 的能量会高估 5.68%。分档后每个代表点内按 DNI 分位再拆开，不再把强弱工况混在一起。
- **误差**（示例，中心瞄准，相对逐时）：20 个代表点 +0.7%，30 个 +0.4%，40 个 +0.25%。中心瞄准的采样误差和受限 APS 的年度结果分开报告。
- 每个全年结果都附采样记录：方式、状态数、气象来源、全年 DNI、瞄准方式。

## 10. 外层：镜场布置优化（`layout_opt.py`）

1. 参数化生成器（径向交错 / 仿生螺旋）铺满场地，生成无碰撞的候选位置。
2. 搜索阶段：按搜索采样（默认 30 个代表点，中心瞄准）计算每个候选位置逐工况的功率；λ_L = 0 时保留年收益最好的 N 个，λ_L > 0 时用交换搜索选出使 J 最大的 N 个，再按“只有已选镜子遮挡”重新定价、重新选择（`selection_iterations` 轮，第 0.2 节），最后整体重算一次。复核阶段对入围参数做至少 6 轮定价和完整换位搜索。
3. 差分进化（多进程）搜索生成器参数，之后做坐标模式搜索微调。可以随时取消，取消后对已找到的方案做复核。
4. **复核**：对前几名方案计算复核采样下的周向 CV 与惩罚，并改用复核采样（默认 40 个代表点 × 3 档 DNI），并启用受限 APS（细网格复核）。同时计算中心瞄准相对逐时全年的采样误差。最后按复核目标 J（受限全年能量 − λ_L × 周向惩罚）重新排名，并报告排名变化。
5. **换位微调**（λ_L = 0）：把最优方案中 APS 全年收益最低的镜子，换成未使用的最佳候选位置；只有 APS 全年能量提高才接受。λ_L > 0 时选择本身已是交换局部最优，跳过这一步。
6. **最终校验**：镜数、边界、禁排区、最小镜距（KD 树）。布不满时状态为 `capacity_shortfall`，报告缺额和最密参数下可布的数量。
7. **上界与存在性**（`layout_opt.upper_bound`）：按第 0.2 节计算单镜潜力图和任意布局的年能量上界，报告理论能量与 APS 可行能量相对上界的差距；镜数超过场地容量上界时给出不存在证明。
8. **可追溯**：每次运行的输入、搜索设置、全部评价历史、候选排名、校验结果、潜力图都保存在独立的运行目录里。

## 11. 光学校验

### 11.1 内部 MCRT（`mcrt.py`）

**误差项**（各自独立）：

- 太阳形状：高斯或圆盘；
- 镜面坡度误差：每条光线随机；
- 跟踪误差：`per_ray` 每条光线随机（与 HFLCAL 的统计口径一致），或 `per_heliostat` 每面镜子一个固定偏置；
- 镜面散射：作用在反射光线上。

**物理过程**：阴影、遮挡和塔影都按光线求交计算。

**统计**：`trace_repeated` 用多个随机种子重复计算，给出总功率和峰值的标准误、峰值格的相对标准误；`convergence` 给出峰值随光线数变化的收敛表。噪声图的最大值偏高，因此比较时使用平均图及其标准误。

### 11.2 SolTrace 对标（`soltrace.py`、`soltrace_driver.py`）

`cspaps soltrace-export` 导出：

- 同场几何、太阳矢量、逐镜位置 / 法向 / 焦距 / 尺寸 / 是否工作；
- 统一的误差定义：法向误差（每轴）= sqrt(坡度² + 跟踪²)；镜面散射作用在反射光线上；两侧都不计大气衰减；
- 本软件在同一网格上的解析通量图和内部 MCRT 结果；
- 一份 PySolTrace 驱动脚本（依据 SolTrace v3.4.0 的 `pysoltrace.py` 接口编写）：建立相同场景（球面镜、吸收圆柱接收器、塔身吸收体），把命中点统计到相同网格，并输出对比摘要（功率、峰值、热点格、NRMSE、相关系数、各次运行的耗时和种子）。

## 12. 已知近似与局限

- HFLCAL 把光斑当作圆对称高斯；大入射角下真实光斑会拉长，示例中截断效率因此偏保守约 0.8%。需要时可改用椭圆核或实测响应。
- 圆柱上下端面视为不透光、不吸热。地形高程可以写进镜位 z，但阴影计算假设镜场大致平坦。
- 云影是二维投影模型，没有考虑云高造成的投影偏移；有实测或预报 DNI 分布时直接输入即可。
- 没有建模集热器内部传热，温度约束用管屏通量上限和偏差系数代替；管壁温差指标需要另外用热模型标定。
- 均匀度启发式给出的是已知最好可行解；最优性差距由第 0.1 节的对偶上界给出（任意规模），小规模问题还可以用 SCIP 精确基准。
- 两类证书都针对模型：候选瞄准点集合、约束点、代表工况采样。加密候选点和工况后，结论随之收敛。

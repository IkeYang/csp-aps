# 模型与算法说明

本文说明 csp-aps 每个计算环节用的模型、公式和近似，以及代码位置。坐标系：x = 东，y = 北，z = 上（m），原点在塔底；方位角按罗盘计（北 = 0°，东 = 90°，顺时针）。

## 0.4 联合姿态与年度加权目标

对固定镜场，令一个方案 a 包含全部镜子的候选点或散焦动作。每次执行评价都使用 a 的整组法向重算遮挡，散焦镜在模型中保留中心姿态并停止向接收器送能。在等面积网格上，吸收热流按截获功率积分归一化。考核区域 H 上的加权目标为 J = P_abs − λ A_H σ_H。CV 上限模式要求正的区域负荷，加权模式在允许停机且最低负荷为零时可取零功率。通量约束使用预测与当前 DNI 的逐镜较大值，并保留设置的安全裕度。

- 候选组合数不超过 `aps.coupled_exact_limit` 时，联合姿态枚举给出数值模型的离散最优解或不可行证明。连续接收器表面的通量峰值用自适应网格及热点加密检查。
- 大问题使用固定响应求解器生成初始方案，再搜索联合姿态。去掉遮挡及非负的均匀度惩罚，逐镜独立选择最大吸收功率，即可得到保守上界。加权模式还以中心化吸收热流的单位方向构造离散度范数的支撑平面。各镜遮挡因子放松为 [0,1]，网格能量归一化因子取各非零光束的积分比值上界。两个上界取较小者。连续瞄准的单独上界由接收器包围球对每面镜张开的方向锥与能量守恒给出。
- 候选集存在性分为已找到可行解、已证不可行和未判定。固定响应矩阵的对偶间隙用于改进方案，界面显示联合姿态证书。

布局搜索的目标为 J_L = Σ w_t [P_t − λ_L S_t]。`uniformity_metric` 可取 `circumferential` 或 `surface`，后者使用同一时刻实际受热面上的二维离散度。生成器筛选先使用管屏分布，复核和连续镜位微调按选择的目标评分。镜数、中心距、场界、禁排区贯穿候选生成和坐标微调。中心瞄准模式评估理论能量，APS 模式使用通过运行可行性检查的时段。标准演示按逐时中心瞄准结果复排。

对于同一批代表工况，几何与堆积给出年能量上界。对于逐时理论目标，对各太阳方位分组保留完整 DNI 时间权重，利用半角余弦函数的凹性、镜位格及接收器的方向锥求单镜能量包络，再应用堆积容量上界。代表工况与逐时目标分别输出上下界。有限评估集有最优解，任意连续镜位上的取到性还要求非空紧可行域和上半连续目标。离散遮挡命中计数会随镜位跳变。

## 0.3 固定响应模型的推导与历史基准

下面的线性响应与对偶推导用于初始方案求解。端到端证明采用上文的联合姿态模型。

### 0.1 问题一：固定镜场的瞄准点优化

**给定**：镜场坐标、镜面数量与尺寸、集热器三维坐标、逐镜 DNI 分布 D_i。**控制变量**：每面定日镜的瞄准点（候选点 k，或散焦）。x_ik ∈ {0, 1}，Σ_k x_ik ≤ 1。

```
P(x)   = Σ c_ik x_ik                        吸收功率（c_ik：候选点 k 的吸收功率）
q(x)   = 考核区 H 各网格的吸收热流（对 x 线性）
S(x)   = A_H · σ_H(q) = a √|H| ‖q − mean(q)‖   （凸函数）
P_H(x) = a Σ_H q                             考核区吸收功率（线性）
通量：  (A x)_m ≤ 1   每个约束点 m（行按允许通量归一化，含安全裕度）

power     max P(x)
weighted  max P(x) − λ S(x)       = P − λ · CV_2D · P_H     λ：均匀性的重要性超参数
cv_limit  max P(x)  s.t.  S(x) ≤ ε P_H(x),  P_H(x) ≥ P_min
```

**存在性**：候选集合有限，"全部散焦"满足全部通量约束，可行集非空，所以 power 和 weighted 模式的最优解一定存在；cv_limit 模式在可行时存在（设置最低负荷后可能不可行）。把瞄准点看成吸热器表面上的连续变量时，可行集是紧集，热流对瞄准点连续，由 Weierstrass 定理最优解同样存在；候选点加密时离散最优值收敛到连续最优值。最优解一般不唯一。

**上界（证书）**：对乘子 ν、μ、ρ ≥ 0，

```
L(x) = P(x) − (λ + μ) S(x) + μ ε P_H(x) + ρ (P_H(x) − P_min) − ν·(A x − 1)
```

对 x 是凹函数，并且在每个可行方案处不小于目标值（弱对偶）。把 x 放松到 [0, 1]，记 Δ 为各镜单纯形的乘积，凹性给出

```
OPT ≤ max_Δ L ≤ L(x_t) + max_{y∈Δ} ∇L(x_t)·(y − x_t)
```

右端按镜可分离（每面镜取系数最大且为正的候选点，否则散焦），只需稀疏矩阵向量乘。x 走 Frank–Wolfe 步（凹一维精确线搜索），乘子走投影次梯度步；**每一步都是有效上界**，取最小。于是

```
本方案目标值 ≤ 全局最优（候选模型） ≤ 上界，   差距 = 1 − 本方案 / 上界
```

cv_limit 模式下若上界为负，即证明在通量和最低负荷约束下不存在满足 CV 目标的方案。上界对本候选集和约束点（求解网格 + 复核热点）成立；只用到更少约束，所以对细网格可行方案同样成立。

**松弛引导取整**：上界迭代同时给出松弛解。按松弛解取整（逐镜取最大分量，以及若干次随机取整）→ 贪心修复通量 → 目标函数下的坐标搜索，保留最好的方案，再做细网格复核（热点加入约束、修复）。只在目标值严格提高且复核通过时替换原方案。

**阿克塞演示**（473 面镜，2024-03-19 15:00，DNI 1136.7 W/m²）：

| 模式 | 吸收功率 (MW) | 二维 CV | 差距 |
| --- | --- | --- | --- |
| 功率最大 | 24.188 | 1.101 | 0.00%（候选集上已证全局最优） |
| λ = 0.3 | 23.25 | 0.256 | 0.11% |
| λ = 1.0 | 21.15 | 0.089 | 1.2% |

测试中用穷举（(K+1)^N 个方案）和 SCIP 精确解验证：上界始终不低于真实最优值。

**证书的范围与连续瞄准点**。证书针对离散候选瞄准点（默认每面镜 3 个方位 × 7 个高度 = 21 个）。真实瞄准点是吸热器表面上的连续量（或受控制器指令分辨率限制）。对连续瞄准点给出严格上界需要目标函数对瞄准位置的 Lipschitz 常数，按光斑梯度估算，这一余量比单面镜的功率还大，没有实用价值。因此软件给出嵌套加密的收敛分析（`cspaps aps-refine`、界面「最优性证书 → 候选点加密收敛性」）：每一级候选网格包含上一级（方位、高度步长减半），从上一级方案出发求解，本方案只增不减，并给出该级上界。阿克塞（λ = 0.3，2024-03-19 15:00）：

| 候选网格（方位步长 / 高度步长） | 本方案 (MW) | 上界 (MW) | 差距 |
| --- | --- | --- | --- |
| 3 × 7（6° / 1.2 m） | 21.462 | 21.487 | 0.11% |
| 5 × 13（3° / 0.6 m） | 21.562 | 21.587 | 0.12% |
| 9 × 25（1.5° / 0.3 m） | 21.595 | 21.611 | 0.07% |

上界逐级增量 +0.100、+0.024 MW，迅速收敛；默认 21 点网格比 1.5° / 0.3 m 网格的方案低约 0.6%。当候选网格取到瞄准控制的指令分辨率时，候选集就是全部可执行方案，证书即完整。

### 0.2 问题二：给定场地的镜场布置

**给定**：场地 Ω（多边形边界、塔周禁排区）、镜数 N、镜面尺寸、集热器三维坐标、经纬度（决定全年太阳位置）与气象。

```
max_X  E(X) = Σ_t w_t Σ_i P_i(X, t)      s.t.  x_i ∈ Ω,  ‖x_i − x_j‖ ≥ d   (i ≠ j)
```

**为什么布局必须考虑均匀性**（`layout_uniformity.py`）。圆柱外置式吸热器的每一侧只被朝向它的定日镜照射：方位 φ_i 的定日镜（从塔轴看）在像平面上看到宽 2R 的吸热器轮廓，表面方位 φ 对应横向坐标 u = R·sin(φ − φ_i)（|φ − φ_i| < 90°）。横向高斯光斑（σ_i）分到方位列 [φ_a, φ_b] 的功率比例为

```
s_ij = [Φ(R sin(φ_b − φ_i)/σ_i) − Φ(R sin(φ_a − φ_i)/σ_i)] / [Φ(R/σ_i) − Φ(−R/σ_i)]
```

与完整 HFLCAL 通量图的列积分相比，最大列误差 0.12%（相关系数 0.999995）。APS 只能沿高度、在几度范围内移动瞄准点，能抹平每列内部的差异，但不能把北侧的热流搬到南侧。等面积列的方差分解

```
σ²_2D = σ²_circ（列平均之间，由布局决定） + 列内方差的平均（APS 可调）
```

说明周向部分是问题一均匀度惩罚中任何瞄准策略都去不掉的部分。布局阶段按**管屏（扇区）**而不是按网格列计算 σ_circ：每列取所在管屏的平均值，再对等面积列求标准差，即面积加权的管屏间标准差（`layout_opt.uniformity_sectors`，默认按管屏；管屏少于 6 块时用 12 个 30° 扇区）。管屏内部的起伏（单个近处镜子的窄光斑只照亮一两列）由瞄准偏移和大量光斑的重叠调平；若按列计算，惩罚会偏爱光斑更宽的远处镜子，在小镜场里选出离群的远镜。按管屏计算也对应工程上的管屏间吸热平衡（每块管屏是一条流程）。只按全年能量布置时，高纬度场址的镜子会集中在塔北侧：阿克塞 473 面镜的能量最优布局有 94.5% 的镜子在塔北，能量质心离塔 173 m，周向 CV 1.03；吸热器南侧 30° 扇区只分到 0.4% 的年热量，北侧 23%。在这个布局上即使用问题一的 λ = 1，二维 CV 也只能降到 0.71，吸收功率还掉了一半。

**带均匀度的目标**（与问题一的加权目标同构，λ_L = `layout_opt.uniformity_weight`）：

```
max_X  J(X) = Σ_t w_t [P_t(X) − λ_L · A_H · σ_circ,t(X)] = Σ_t w_t P_t (1 − λ_L CV_circ,t)
```

σ_circ,t 为工况 t 下考核区各管屏平均吸收热流的标准差。固定生成参数时，从候选镜位中选 N 个是 max J(x)，Σx = N，x ∈ {0,1}；J 对松弛变量是凹函数，用交换局部搜索求解，并用 Frank–Wolfe 上界（线性子问题为取前 N 大）证明选择的差距。λ_L = 0 时退化为“年收益最高的 N 个”。

**候选镜位的定价必须与选择一致**（`layout_opt.select_consistent`）。生成器先铺满场地（阿克塞约 2,300 个候选位置，最终只建 473 面）。若在全部候选组成的密集镜场里计算每个位置的功率，每个候选都要承受从不建造的候选造成的阴影遮挡；这一人为损失随候选密度变化且不随距离单调——阿克塞北侧 230–290 m 的候选密集，平均只有 74–76 MWh，而 290–330 m 处生成器换区、邻居变少，反而有 78–80 MWh。于是选择会跳过近处位置，选出离主镜场 85 m 的 3 面孤立远镜（审计发现）。现在的做法：

1. 只让已选镜子遮挡，重新计算所有候选的功率（已选镜子得到真实功率，未选候选得到“加入当前布局后”的功率）；
2. 从当前选择出发重新选择；只有当真实目标值提高时才接受这一步，否则把允许的换位数减半（阻尼），因此不会来回振荡；
3. 复核阶段再做完整换位邻域搜索：对每面已选镜子，在排名靠前的 300 个候选中精确找最优替换。筛选换位对时除了单步增益，还用线性化目标（同一扇区内换位时惩罚变化相互抵消），否则同扇区的有利换位会被漏掉。

结果对每个选择都校验“没有任何单次换位能提高目标值”（测试中逐对穷举），并报告脱离主镜场的镜子数（与主镜场距离超过中位镜距 3 倍的连通分量）。阿克塞 λ_L = 0.3：孤立远镜从 3 面降为 0，全年理论吸收由 33,700 变为 33,709 MWhₜₕ，受限 APS 可行能量由 32,140 提高到 32,167 MWhₜₕ。

| --- | --- | --- | --- | --- | --- |
| 0 | 35,826 | 1.07 | 170 m | 95% | — |

两种布局在问题一中的表现（2024-03-19 15:00，DNI 1136.7 W/m²，细网格复核）：

| 问题一的权重 λ | λ_L = 0 布局：吸收功率 / 二维 CV / 周向 CV | λ_L = 0.3 布局：吸收功率 / 二维 CV / 周向 CV |

**存在性**：可行集 {X : x_i ∈ Ω, ‖x_i − x_j‖ ≥ d} 有界且闭，即紧集；年能量与周向惩罚都对镜位连续（阴影遮挡是面积分数，随镜位连续变化），所以只要可行集非空，最优布置一定存在。对称场地上最优布置一般不唯一。

**上界**：e0(x) 为位置 x 处单镜在**无邻镜**时的年吸收热量（余弦、反射、衰减、截断、吸收率）。邻镜阴影遮挡和通量约束只会减少能量，所以 E(X) ≤ Σ e0(x_i)。再用层饼积分：

```
Σ_i e0(x_i) = ∫_0^∞ #{i : e0(x_i) ≥ t} dt ≤ ∫_0^∞ min(N, cap(L_t)) dt,     L_t = {x ∈ Ω : e0(x) ≥ t}
cap(S) ≤ area(S ⊕ B(d/√3)) / (√3 d² / 2)
```

后一式来自 Fejes Tóth：镜距 ≥ d 的点集，各点 Voronoi 胞与半径 d/√3 圆盘的交互不重叠、面积不小于 √3 d²/2。

**栅格上的严格做法**（`certify.cell_energy_upper_bound`）。场地用正方形栅格覆盖（所有与场地相交的格子），对每个格子求一个对格内**任意位置**都成立的 e0 上界，而不是只在格子中心取样：设格子半对角线 ρ，镜→瞄准点向量 v(x) 与格子中心的 v(c) 相差不超过 ε = ρ(1 + R/r_min) + √(2R² + (H/2)²)（后一项允许瞄准点在吸热器可见面上任意移动，所以上界对任何瞄准策略都成立），方向最多转过 δ = asin(ε/|v(c)|)。逐工况：

| 因子 | 格内上界 |
| --- | --- |
| 余弦 cos(θ/2) | cos(max(0, θ_c − δ)/2) |
| 大气衰减（随斜距单调递减） | 斜距取 \|v(c)\| − ε 时的值 |
| 截断 | 吸热器轮廓包含在 \|u\| ≤ R、\|v\| ≤ (H/2)cosβ + R sinβ 的矩形内；居中矩形的高斯质量最大，σ 取格内最小值 D_min·σ_0 |
| 吸收率 | 光斑可能落到的管屏中的最大吸收率，加 5σ 尾部按全局最大吸收率计 |

层饼积分中的区域 L_t 取上界 ≥ t 的格子之并，圆盘膨胀半径取 d/√3 + √2·格宽（格内任意位置 + 格子部分覆盖）。这样每一步都是不等式，不依赖采样密度。

**审计修正**（2026-11-21）：此前用格子中心取样再取 3×3 邻域最大值，峰值落在格点之间时会略微低估；单镜只按正对管屏的吸收率计算，而光斑会落到相邻管屏；快速能量计算（不算通量图时）用全部管屏的平均吸收率。三处都已修正：上界改为上面的逐格严格界；吸收率按光斑在各管屏上的分布加权（`receiver.effective_absorptivity`，与细网格通量图一致）；差距不再截断为 0，若本方案超过上界则报告 `bound_violation`。对 2 万个随机位置、正对/相邻管屏吸收率相差 3 倍的算例做了校验，没有任何位置超过所在格子的上界。

- 若 N 大于整个场地的容量上界，即证明**不存在**满足镜距的布置；
- 否则给出 “本方案 ≤ 全局最优 ≤ 上界” 与差距。上界忽略阴影遮挡并允许最密堆积，偏乐观；真实最优值介于两者之间。
- λ_L > 0 时 J ≤ E（管屏间惩罚 ≥ 0），所以能量上界同样是 J 的上界，结果中单独报告为 `gap_objective_conservative`（阿克塞约 21%）。没有比这更紧的通用上界：任何布局都可能在管屏间分配上恰好均衡，惩罚的下界只能取 0；此时布局为了均匀受热主动让出部分能量，能量差距相应变大（阿克塞 λ_L = 0.3：14.2%），这部分差距是均匀性的代价，不是搜索不足。

**阿克塞演示**（N = 473，840 m × 780 m 场地，禁排半径 50 m，6 个复核工况）：任意布局、任意瞄准策略的年吸收热量上界 39,283 MWhₜₕ。只追求能量（λ_L = 0）时全年理论吸收 36,435 MWhₜₕ，差距 ≤ 7.3%；演示默认 λ_L = 0.3，全年理论吸收 33,709 MWhₜₕ（差距 ≤ 14.2%），受限 APS 可行能量 32,167 MWhₜₕ。


## 1. 功率链

每面镜子 i 送到集热器表面的截获功率：

```
P_i = DNI_i · A · η_cos · ρ·清洁度 · η_阴影 · η_遮挡 · η_衰减 · η_截断
```

吸收功率 = 截获功率 × 吸收率（可按管屏设置吸收率）。各环节按顺序记录在 `simulate.STAGES`，结果中同时给出截获功率和吸收功率。`DNI_i` 可以逐镜不同（云影）；散焦的镜子截断为 0。

| 环节 | 模型 | 代码 |
| --- | --- | --- |
| 太阳位置 | NREL SPA（pvlib） | `sun.solar_position` |
| DNI | Meinel 晴空模型 + 海拔修正 / 常数 / 气象文件（EPW、CSV） | `sun.dni`, `sun.load_weather` |
| 余弦 | 镜面法向 = 太阳方向与镜→瞄准点方向的角平分线 | `optics.heliostat_geometry` |
| 阴影、遮挡 | 镜面采样点的光线–矩形求交，含塔影 | `shading.shading_blocking` |
| 大气衰减 | Vittitoe-Biggs 晴天 / 霾天，或 Beer-Lambert | `optics.attenuation` |
| 光斑与截断 | HFLCAL 圆高斯 + 圆柱面投影 + 一维求积 | `optics.beam_sigma`, `optics.intercept_fraction` |
| 通量分布 | 全部光斑在圆柱面上线性叠加 | `optics.flux_on_receiver` |

## 2. 集热器、管屏与通量限值

圆柱面按 `n_panels` 等分为管屏，1 号管屏从 `panel_start_azimuth_deg` 开始顺时针。每个点的允许通量：

```
允许入射通量(点) = 管屏限值 × 高度系数(z) ÷ [吸收率（若限值按吸收通量给出）] ÷ 管屏偏差系数
```

- 高度系数 `limit_height_profile` 从下到上线性插值；
- 偏差系数 `panel_flux_bias` = 实测通量 / 模型通量，是运行反馈的接口：某块管屏实测比模型高 10%，就填 1.1，该管屏的允许模型通量自动降低；
- 优化器、复核、界面和命令行都统一换算成"允许的模型入射通量"来比较（`receiver.incident_limit_w_m2`）。

## 3. 阴影与遮挡

- 定日镜为矩形，方位–高度角跟踪（宽度方向保持水平），每面镜子取 n×n 个采样点（默认 8×8）。
- **阴影**：采样点向太阳的光线打到邻近镜子或塔身（竖直圆柱，高至集热器顶）。
- **遮挡**：采样点向瞄准点的反射光线打到邻近镜子。损失按并集计算，不重复扣除。
- **邻居筛选**：KD 树找一定半径内的镜对（半径由太阳高度角和反射光仰角决定，缓存在镜场上），每个时刻再只保留光线方向走廊内（横向距离小于对角线）的邻居。
- **筛选复核**（`shading.compare_screening`、`cspaps shading-check`）：与不做任何筛选的全对暴力求交逐镜比较。在低太阳高度角、密集镜位、远端镜、边缘瞄准四种工况下，示例镜场都完全一致（漏判 0），筛选快 40–200 倍。因此没有另外引入 SolTrace 式的投影索引。

## 4. 光斑模型（HFLCAL）

像平面上的光斑为圆高斯，标准差：

```
σ = D · sqrt(σ_sun² + (2σ_slope)² + (2σ_track)² + σ_spec² + σ_ast²)
```

| 符号 | 含义 |
| --- | --- |
| D | 斜距 |
| σ_sun | 太阳形状（高斯取 σ，圆盘取 半角/2） |
| σ_slope, σ_track | 镜面法向误差，反射后角度加倍 |
| σ_spec | 镜面散射，作用在反射光线上，不加倍 |
| σ_ast | 像散项 |

像散项：`σ_ast = sqrt(0.5·(H_t² + W_s²)) / (4D)`，`H_t = d·|D/f − cos ω|`，`W_s = d·|D/f·cos ω − 1|`。

- **投影到圆柱面**：表面点沿主光线投影到像平面，乘入射余弦；背光半圆为 0。
- **截断效率**：对圆柱侧面在像平面上的投影带做一维 Gauss-Legendre 积分，节点集中在光斑中心 ±8σ，与网格粗细无关。同一公式可以只对某个高度带积分，第 8 节的边缘带上界就用它来算带内功率。

## 5. 内层：瞄准点优化（APS）

### 5.1 问题

固定镜场和时刻，为每面镜子 i 选一个候选点 k，或者让它散焦：

```
max   Σ_i D_i · p_ik
s.t.  Σ_i Dc_i · K_ik(m) ≤ (1 − 裕度) · F_lim(m)      对每个约束点 m
```

- `K_ik` 是单位 DNI 下的通量响应（含光斑、遮挡和光学损失）；
- `D_i` 是当前 DNI，`Dc_i` 是约束用 DNI（当前值，或预报时段内的最大值）。
- 候选点为正对方位加周向偏移（默认 −4°、0、+4°），乘以高度层（默认 9 层，覆盖 90% 高度）。每个候选点都重算法向、余弦、斜距、σ 和截断效率。

### 5.2 响应与 DNI 分离（`aps.ResponseSet`）

与 DNI 无关的部分只建一次：几何、遮挡、截断效率，以及稀疏的单位 DNI 响应（保留不低于自身峰值 0.2% 的网格）。每轮更新 DNI 只需要逐行缩放。

阴影与遮挡**按每个候选瞄准点分别计算**（`ResponseSet.sb_k`）：不同瞄准点对应不同的镜面法向和反射光方向。高太阳时差别为零，低太阳时可达 20 个百分点（阿克塞 12 月 21 日 09:30，473 面镜中 80 面差别超过 0.5%），计算耗时 0.04–0.5 s。

求解网格会按最窄光斑自动加密（单格不超过 σ_min/1.5），细节由下面的复核兜底。

### 5.3 求解器

| 方法 | 做法 |
| --- | --- |
| `center` | 全部瞄准正对面的中心高度（基准） |
| `kfactor` | z = z_c ± (H/2 − kσ_i)，按扇区上下交替；二分求满足限值的最大 k |
| `greedy`（默认） | 冷启动：按光斑从大到小依次放置，选可行且功率最高的候选点，平局时选局部通量最低的点；之后做坐标下降。热启动：从上一轮已执行方案出发，先让造成超限的镜子移开或散焦，再重算优先集合（DNI 变化大、处在热点附近、处于散焦或刚恢复可用的镜子） |
| `milp` | 0/1 整数规划（HiGHS），用于小规模；其 LP 松弛给出功率上界 |

单时刻计算（`cspaps aps`、界面「瞄准优化」）默认在上述求解之后运行第 0.1 节的证书：对偶上界 + 松弛引导取整，结果附 `certificate`（上界、差距、状态）和 `existence`（存在性结论）。全年和布局循环内不运行证书，以保持速度。`cspaps pareto` 扫描权重 λ，每个点都是完整流程（坐标搜索、松弛取整、细网格复核、上界）。

附加约束：

- 可用状态：不可用的镜子强制散焦；
- 可达性：候选点要求的法向变化须在"转速 ×（延迟 + 周期）"以内；
- 移动惩罚：瞄准点移动越远，扣除的功率越多，使方案平滑变化。

### 5.4 可行性复核与约束生成（`verify.py`）

求解用的是粗网格和截尾光斑，粗网格会漏掉窄光斑的峰值：导师给的算例中，12×8 网格报 4.18 kW/m²，真实峰值是 19.5。所以每个解都要复核：

1. 网格间距 ≤ σ_min/3，σ_min 是当前方案里最窄的光斑；
2. 用约束 DNI 完整叠加全部光斑，不截尾；
3. 在最热的若干个局部极大点周围，用 1/4 间距的 9×9 子网格精化峰值，误差小于 0.4%；
4. 每个点与该点所在管屏的允许通量比较。

超过"允许值（扣除裕度）"的局部极大点加入约束集，重新求解，最多 `verify_max_rounds` 轮。最终状态：

| 状态 | 含义 |
| --- | --- |
| `ok` | 不超过扣除裕度后的允许值 |
| `margin_reduced` | 不超过限值，但用掉了部分裕度 |
| `infeasible` | 超过限值，同时给出热点位置、所在管屏、超限量和主要贡献镜 |

命令行在 `infeasible` 时返回退出码 2。

**复核的收敛与标签**。精确法（MILP）每轮都从头求解，新的约束点可能把通量推到别处，割平面轮数事先无法保证（审计中一个小算例需要 5 轮，而默认上限是 4 轮）。现在 MILP 最多 12 轮；若仍不通过，就从当前方案出发修复——只移动或散焦供给超限点的镜子，直到通过复核。只有当最终方案就是精确法自己的最优解（没有经过修复）**并且**通过细网格复核时，才标记 `global_optimality_proven`；复核失败的方案标为 `infeasible_after_verification`，也不会附带最优性证书。

**单时刻结果的最终复核**（`workflows.task_aim`）：不再沿用求解器内部的复核，而是对最终瞄准点重新计算阴影遮挡、用完整光斑在细网格上复核（有预报时用约束 DNI），状态由这一复核决定；求解器的复核作为 `solver_flux_check` 一并保存。

## 6. 均匀受热（第五、六节）

### 6.1 指标

H 为预热器考核区（若干管屏和高度范围），暗区也计入面积；q 为吸收通量。

- 二维 CV = 面积加权标准差 / 面积加权均值；
- 周向 CV：先按高度求平均，再在各列之间算 CV；
- 高度 CV：先按周向求平均，再在各行之间算 CV。

以示例在夏至 13:40 的贪心解为例：二维 CV 0.717、周向 0.142、高度 0.694，可见上下受热差在周向汇总中被掩盖了。

### 6.2 带均匀度约束的 APS（`uniformity.solve_uniform`）

```
max P_abs   s.t.  通量限值，CV_2D(H) ≤ ε，A_H·q̄_H ≥ P_H,min
```

用拉格朗日局部搜索求解：最大化 `P_abs − μ·A_H·std_H(q)`。单面镜子换点时，Σq 和 Σq² 可以增量更新；对权重 μ 做二分，取满足 ε 的最小 μ。

- 固定权重模式（`mode: weighted`）直接最大化 `P_abs − λ·A_H·σ_H`，坐标搜索跑到没有改进为止（上限 25 轮）；
- 达不到最低负荷时记为 `below_min_load`，按停机处理（全部散焦）；
- 示例（夏至 13:40）：ε = 0.55 时二维 CV 从 0.717 降到 0.548，截获功率只降 0.3%。

### 6.3 ε 扫描与精确基准

`uniformity.sweep` 给出功率–均匀度曲线。启发式结果标为"已知最好可行"或"未达到"。小规模问题可以加 `--exact`，用 SCIP 解混合整数二阶锥规划，状态为"已证最优""除停机外不可行""限时可行"之一。测试中验证了：放宽 ε 时，被证明的最优功率单调不减。

### 6.4 上下边缘功率上界（第六节，`uniformity.edge_band_bound`）

B 为顶、底各 1/8 高度的两条带，面积占比 a = 0.25。要求总截获功率至少为 L，放松峰值和均匀度约束：

```
U(λ) = Σ_i max_k (b_ik + λ p_ik) − λL ≥ P_B，   λ ≥ 0
u = min_λ U(λ) / L
CV_2D ≥ max(0, a − u) / sqrt(a(1 − a))
```

其中 b_ik 是候选点 k 落在 B 内的功率，用精确的高度带截断效率计算。

示例中取 L 为贪心解功率的 99.5%，得到 u ≤ 8.0%，二维 CV 下界 0.39，与评审稿的数值一致。只有当已证下界高于目标时，才把该目标标为"在此候选集模型下不可达"。

## 7. 在线控制引擎（`engine.py`）

每个控制周期调用一次 `APSEngine.step(ControlRequest)`。

**输入**：时刻、逐镜当前 DNI 及其时间戳、带有效时刻的预报快照、镜子可用状态、上一轮执行回执。

**处理流程**：

1. **数据检查**。DNI 缺失、非法或过期（超过 `max_dni_age_s`）时，约束改用晴空 DNI。若预报没有覆盖方案生效时段 [t + 延迟, t + 延迟 + 周期]，也用晴空 DNI。
2. **约束 DNI**。取覆盖时段内各预报快照的逐镜最大值，乘以 (1 + 预报裕度)，且不低于当前值。没有预报时，默认按晴空 DNI（保守）。
3. **响应缓存**。太阳移动不超过 `response_refresh_deg` 时复用；历次复核加入的热点约束点也一并保留。
4. **热启动求解**。从回执中的已执行方案出发，带可达性筛选和求解时限。
5. **最终复核**。用当前太阳几何（重算遮挡）和约束 DNI 在细网格上复核；有热点就加入约束、修复。仍不通过时按配置回退：上一轮方案能通过复核就沿用，否则散焦主要贡献镜。

**状态**：`ready`（可执行）、`fallback`（已回退，附原因）、`infeasible`（不可执行，由控制端进入保守策略）。场站的安全联锁独立于 APS，保持不变。

示例算例（1532 面镜）的耗时：冷启动约 3.4 s，其中构建响应约 1.9 s；复用缓存时约 0.35–0.45 s，其中求解只要 0.06–0.13 s。

**服务方式**：`cspaps engine CASE` 以 JSON 行的形式从标准输入读请求、向标准输出写响应，DNI 可以按镜子 ID 给出。

## 8. 云影回放（`realtime.py`）

**场景**：随机云、云边扫过（`moving_edge`）、云突然移开（`sudden_clear`），以及 DNI 数据延迟（`dni_delay_s`）或丢失（`dni_dropout_s`）。

**时间口径**：采样时刻为 0、步长、2×步长……以及回放终点；第 k 个采样代表区间 [t_k, t_k+1)，终点区间长度为 0。

- 能量 = Σ 功率 × 区间长度；
- 超限时长 = 超限采样所代表区间的长度之和；
- 3 分钟回放（60 s 步长）共 3 个区间，150 s 回放为 60、60、30 s。

**判定方式**：在 t_k 算出的方案从 t_k+1 起生效（一个周期的延迟）。每个生效方案都用实际 DNI 做细网格复核，超限判定以复核结果为准。

**结果**：同时输出各策略的端到端延迟 P50/P95、冷启动次数、超时次数和方案状态统计。

## 9. 全年能量与采样（`sun.py`）

| 方式 | 做法 |
| --- | --- |
| `sun_bins` | 全年白天各时刻的太阳方向做 DNI 能量加权 k-means（竖直分量放大 3 倍，使低太阳高度角分得更细）；20 / 30 / 40 或任意个数 |
| `sun_grid` | 按太阳高度角 × 方位角分箱 |
| `hourly` | 全年逐时；有气象文件时用文件原始步长 |
| `representative_days` | 每月一天 |

- **能量守恒**：每个代表点的 DNI × 权重 = 所含小时的 DNI 能量之和，全年 DNI 总量严格守恒。
- **DNI 分档**（`dni_bands`）：受限 APS 的功率对 DNI 不是线性的。评审稿指出，DNI 300 和 1200 W/m² 的工况合并后，受限 APS 的能量会高估 5.68%。分档后每个代表点内按 DNI 分位再拆开，不再把强弱工况混在一起。
- **误差**（示例，中心瞄准，相对逐时）：20 个代表点 +0.7%，30 个 +0.4%，40 个 +0.25%。中心瞄准的采样误差和受限 APS 的年度结果分开报告。
- 每个全年结果都附采样记录：方式、状态数、气象来源、全年 DNI、瞄准方式。

## 10. 外层：镜场布置优化（`layout_opt.py`）

1. 参数化生成器（径向交错 / 仿生螺旋）铺满场地，生成无碰撞的候选位置。
2. 搜索阶段：按搜索采样（默认 30 个代表点，中心瞄准）计算每个候选位置逐工况的功率；λ_L = 0 时保留年收益最好的 N 个，λ_L > 0 时用交换搜索选出使 J 最大的 N 个，再按“只有已选镜子遮挡”重新定价、重新选择（`selection_iterations` 轮，第 0.2 节），最后整体重算一次。复核阶段对入围参数做至少 6 轮定价和完整换位搜索。
3. 差分进化（多进程）搜索生成器参数，之后做坐标模式搜索微调。可以随时取消，取消后对已找到的方案做复核。
4. **复核**：对前几名方案计算复核采样下的周向 CV 与惩罚，并改用复核采样（默认 40 个代表点 × 3 档 DNI），并启用受限 APS（细网格复核）。同时计算中心瞄准相对逐时全年的采样误差。最后按复核目标 J（受限全年能量 − λ_L × 周向惩罚）重新排名，并报告排名变化。
5. **换位微调**（λ_L = 0）：把最优方案中 APS 全年收益最低的镜子，换成未使用的最佳候选位置；只有 APS 全年能量提高才接受。λ_L > 0 时选择本身已是交换局部最优，跳过这一步。
6. **最终校验**：镜数、边界、禁排区、最小镜距（KD 树）。布不满时状态为 `capacity_shortfall`，报告缺额和最密参数下可布的数量。
7. **上界与存在性**（`layout_opt.upper_bound`）：按第 0.2 节计算单镜潜力图和任意布局的年能量上界，报告理论能量与 APS 可行能量相对上界的差距；镜数超过场地容量上界时给出不存在证明。
8. **可追溯**：每次运行的输入、搜索设置、全部评价历史、候选排名、校验结果、潜力图都保存在独立的运行目录里。

## 11. 光学校验

### 11.1 内部 MCRT（`mcrt.py`）

**误差项**（各自独立）：

- 太阳形状：高斯或圆盘；
- 镜面坡度误差：每条光线随机；
- 跟踪误差：`per_ray` 每条光线随机（与 HFLCAL 的统计口径一致），或 `per_heliostat` 每面镜子一个固定偏置；
- 镜面散射：作用在反射光线上。

**物理过程**：阴影、遮挡和塔影都按光线求交计算。

**统计**：`trace_repeated` 用多个随机种子重复计算，给出总功率和峰值的标准误、峰值格的相对标准误；`convergence` 给出峰值随光线数变化的收敛表。噪声图的最大值偏高，因此比较时使用平均图及其标准误。

### 11.2 SolTrace 对标（`soltrace.py`、`soltrace_driver.py`）

`cspaps soltrace-export` 导出：

- 同场几何、太阳矢量、逐镜位置 / 法向 / 焦距 / 尺寸 / 是否工作；
- 统一的误差定义：法向误差（每轴）= sqrt(坡度² + 跟踪²)；镜面散射作用在反射光线上；两侧都不计大气衰减；
- 本软件在同一网格上的解析通量图和内部 MCRT 结果；
- 一份 PySolTrace 驱动脚本（依据 SolTrace v3.4.0 的 `pysoltrace.py` 接口编写）：建立相同场景（球面镜、吸收圆柱接收器、塔身吸收体），把命中点统计到相同网格，并输出对比摘要（功率、峰值、热点格、NRMSE、相关系数、各次运行的耗时和种子）。

## 12. 已知近似与局限

- HFLCAL 把光斑当作圆对称高斯；大入射角下真实光斑会拉长，示例中截断效率因此偏保守约 0.8%。需要时可改用椭圆核或实测响应。
- 圆柱上下端面视为不透光、不吸热。地形高程可以写进镜位 z，但阴影计算假设镜场大致平坦。
- 云影是二维投影模型，没有考虑云高造成的投影偏移；有实测或预报 DNI 分布时直接输入即可。
- 没有建模集热器内部传热，温度约束用管屏通量上限和偏差系数代替；管壁温差指标需要另外用热模型标定。
- 均匀度启发式给出的是已知最好可行解；最优性差距由第 0.1 节的对偶上界给出（任意规模），小规模问题还可以用 SCIP 精确基准。
- 两类证书都针对模型：候选瞄准点集合、约束点、代表工况采样。加密候选点和工况后，结论随之收敛。

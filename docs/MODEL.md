# 模型与算法说明

本文说明 csp-aps 里每个计算环节用的模型、公式和近似，以及它们在代码中的位置。

坐标系：x = 东，y = 北，z = 上（m），原点在塔底；方位角按罗盘计（北 = 0°，东 = 90°，顺时针）。

## 1. 功率链

每面镜子 i 在某一时刻送到集热器表面的功率：

```
P_rec,i = DNI_i · A · η_cos · ρ·清洁度 · η_shading · η_blocking · η_att · η_int
```

各项按顺序记录在 `simulate.STAGES`，每一步的功率都会输出，方便看损失出在哪个环节。`DNI_i` 可以每面镜子不同（云影）。散焦的镜子 `η_int = 0`。

| 环节 | 模型 | 代码 |
| --- | --- | --- |
| 太阳位置 | NREL SPA（pvlib） | `sun.solar_position` |
| 晴空 DNI | Meinel 模型 + Laue 海拔修正；或常数；或气象文件 | `sun.dni`, `sun.load_weather` |
| 余弦 | 镜面法向 = 太阳方向与镜→瞄准点方向的角平分线 | `optics.heliostat_geometry` |
| 阴影、遮挡 | 镜面采样点光线-矩形求交，含塔影 | `shading.shading_blocking` |
| 大气衰减 | Vittitoe-Biggs 晴天/霾天，或 Beer-Lambert | `optics.attenuation` |
| 光斑与截断 | HFLCAL 圆高斯 + 圆柱面投影 + 一维求积 | `optics.beam_sigma`, `optics.intercept_fraction` |
| 通量分布 | 全部光斑在圆柱面网格上线性叠加 | `optics.flux_on_receiver` |

## 2. 阴影与遮挡

- 定日镜为矩形，方位-高度角跟踪：宽度方向保持水平。
- 每面镜子取 n×n 个采样点（默认 8×8）。
- **阴影**：从采样点向太阳方向发出的光线，如果打到邻近镜子或塔身（竖直圆柱，高到集热器顶），该点被遮。
- **遮挡**：从采样点向瞄准点的反射光线，如果打到邻近镜子，该点被挡。
- 损失按"被遮或被挡"的并集计算，不会重复扣除。
- 邻居搜索：先用 KD 树找出一定半径内的所有镜子对。半径由最低太阳高度角和反射光仰角决定，并缓存在镜场对象上。每个时刻再只保留光线方向"走廊"里的邻居（横向距离小于对角线长度），所以计算量很小。

## 3. 光斑模型（HFLCAL）

像平面（过瞄准点、垂直于主光线）上的光斑为圆高斯分布，标准差：

```
σ = D · sqrt(σ_sun² + (2σ_slope)² + (2σ_track)² + σ_ast²)
```

- D 为斜距。
- σ_sun：太阳形状。高斯形状直接取 `sigma_mrad`；圆盘形状取 半角/2。
- 斜率误差和跟踪误差都是镜面法向误差，反射后角度加倍。
- 像散项：

```
σ_ast = sqrt(0.5·(H_t² + W_s²)) / (4D)
H_t = d·|D/f − cos ω|
W_s = d·|D/f·cos ω − 1|
```

  其中 d = sqrt(镜面积)，ω 为入射角，f 为焦距。按斜距聚焦时 f = D，平面镜时 f = ∞。

**投影到圆柱面**：集热器表面点沿主光线方向投影到像平面，取该处高斯值，再乘以光线与表面法向的夹角余弦。背光的半圆为 0。这样处理时，整个圆柱面上的通量积分恰好等于光斑落在圆柱侧面轮廓内的那部分能量。

**截断效率**：圆柱侧面在像平面上的投影是一条带。横坐标 U ∈ [−R, R] 处的竖直母线投影为纵坐标区间 [v_bot(U), v_top(U)]，所以

```
η_int = ∫ φ(u) · [Φ(v_top/σ) − Φ(v_bot/σ)] dU
```

用 48 点 Gauss-Legendre 积分，节点集中在光斑中心 ±8σ 内。结果与通量图网格的粗细无关，光斑再窄也能分辨。和解析解（水平光线时等于两个 erf 的乘积）对比，误差小于 10⁻⁶。

## 4. 内层：瞄准点优化（APS）

**问题定义**：给定镜场和时刻，为每面镜子 i 在候选瞄准点 k 中选一个，或者让它散焦：

```
max   Σ_i P_i,k(i)
s.t.  Σ_i F_i,k(i)(m) ≤ (1 − 安全裕度) · F_max      对集热器每个网格 m
```

- **候选点**：每面镜子正对的集热器方位上加若干周向偏移（默认 −4°、0、+4°），再乘以若干高度层（默认 7 层，覆盖集热器高度的 80%）。每个候选点重新计算镜面法向、余弦、斜距、σ 和截断效率，所以偏离中心瞄准带来的溢出损失和余弦变化都被计入。
- **光斑缓存**：每个候选点的光斑预先算好，只保留不低于自身峰值 0.2% 的网格（约 3.5σ 范围）。舍去的尾部约占 0.2% 的能量，由安全裕度覆盖；最终评估用的是完整光斑。
- **约束与目标可以用不同的 DNI**：目标用当前 DNI，约束用预报的最大 DNI。

求解器：

| 方法 | 做法 | 用途 |
| --- | --- | --- |
| `center` | 全部瞄准正对面的中心高度 | 基准 |
| `kfactor` | 瞄准高度 z = z_c ± (H/2 − kσ_i)，按扇区上下交替；用二分法找满足通量上限的最大 k（溢出最少） | 快速基线 |
| `greedy`（默认） | 按光斑从大到小依次放置（image-size priority）：每面镜子选可行且功率最高的候选点，功率相差不超过 0.5% 时选局部通量最低的点；之后做若干轮坐标下降，每次取出一面镜子重新选点 | 实时运行，可扩展到大镜场 |
| `milp` | 0/1 整数规划，用 HiGHS 求解 | 小规模问题的精确解；其 LP 松弛给出功率上界，用来衡量贪心法离最优还差多少 |

**实时运行的附加功能**：
- 移动惩罚 `move_penalty_per_m`：候选点离上一时刻瞄准点越远，扣除越多功率，使瞄准点平滑变化。
- 散焦：找不到可行瞄准点时，让镜子散焦待机。

## 5. 云影与实时仿真

- 云影是做匀速平移的软边圆盘，盘内 DNI 乘以透过率。可以逐个指定，也可以随机生成。
- 实测 DNI 分布可从 CSV（x, y, dni）读入，插值到每面镜子。
- 控制循环：每个刷新周期读入太阳位置和各镜子的 DNI，求解 APS，新瞄准点在下一个周期生效（一个周期的延迟）。
- 对比三种策略：
  - `center`：不做 APS；
  - `aps_reactive`：只用当前 DNI；
  - `aps_predictive`：约束用预报时长内每面镜子的最大 DNI。
  
  预报型策略可以避免云移走、DNI 突然回升时的瞬时超通量。

## 6. 全年能量

三种方式（`annual.method`）：

| 方式 | 做法 | 示例算例上的误差 / 耗时 |
| --- | --- | --- |
| `hourly` | 全年逐时（或用气象文件的步长） | 基准，约 3.5 分钟 |
| `sun_bins`（默认） | 对全年白天各时刻的太阳方向做 DNI 能量加权的 k-means 聚类，得到 20–40 个代表太阳位置，每个位置配一个代表 DNI 和权重 | 30 个代表点 +0.4%，40 个 +0.25%，约 1–2 s |
| `representative_days` | 每月取一天，逐时计算 | 约 +0.05%，约 6 s |

`sun_bins` 的几个细节：
- 聚类时太阳矢量的竖直分量乘以 3，让低太阳高度角（阴影变化快）分得更细。
- 每个代表点的 DNI × 权重等于其成员的 DNI 能量之和，所以全年 DNI 总量严格守恒。

全年计算可以用 `aiming: center`，也可以用 APS（每个时刻都满足通量上限）。

## 7. 外层：镜场布置优化

**目标**：镜子数量固定为 N，使全年集热器接收能量最大。

1. 参数化生成器在场地边界内铺满候选位置。可选：
   - 径向交错：参数为径向排距、排距增长系数、周向间距；分区布置，保证任意两镜间距 ≥ 防碰撞直径；
   - 仿生螺旋：r_k = a·DM·k^b，θ_k = k·黄金角，生成后去除碰撞。
2. 用代表太阳位置和中心瞄准，计算每个候选位置的全年能量（含阴影遮挡）。
3. 保留全年能量最高的 N 个位置，再对保留下来的镜场重新计算一次（邻居少了，阴影遮挡会变）。
4. 用差分进化搜索生成器参数，可多进程并行。
5. 对前几名方案用 APS 重算全年能量（每个代表时刻都满足通量上限），按这个结果选出最终方案。这一步考虑了为均匀受热而偏离中心瞄准所带来的额外溢出损失。

输出：
- 最优镜场坐标 CSV；
- 一份可直接使用的新算例 YAML（`field.layout_file` 指向上面的 CSV）；
- 搜索历史和排名。

## 8. MCRT 校验

独立的蒙特卡洛光线追迹，不进入任何优化循环。每面镜子从镜面随机点发射光线：

1. 太阳方向按太阳形状抽样（高斯或圆盘）；
2. 阴影：向太阳方向的光线与邻近镜子和塔身求交；
3. 局部法向：理想轴上球面聚焦，加上随机的斜率误差和跟踪误差；
4. 镜面反射后做遮挡测试；
5. 乘以大气衰减，再与圆柱侧面求交；
6. 命中点按同一网格统计成通量图。

`compare` 会逐个环节对比效率，并给出通量图的归一化均方根误差（NRMSE）和相关系数。示例算例的对比结果见 README。

## 9. 已知近似与局限

- HFLCAL 把光斑当作圆对称高斯；大入射角下，真实光斑会被拉长（MCRT 能体现这一点）。示例中截断效率因此偏保守约 0.8%。
- 圆柱上下端面视为不透光且不吸热。
- 地形高程可以写进镜场坐标的 z，但阴影计算中假设镜场大致平坦。
- 云影是二维投影模型，不考虑云高和太阳角造成的投影偏移。如果有实测或预报的 DNI 分布，直接用 `--dni-map` 输入即可。
- 集热器内部传热和热损失没有建模，用通量上限代替温度约束。
